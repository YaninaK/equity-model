# Cтруктура `config/`

```
config/
├── base.yaml                    # Общие настройки (не меняются часто)
├── data.yaml                    # Настройки данных и источников
├── clustering.yaml              # Параметры кластеризации (Этап 2)
├── regimes.yaml                 # Рыночные режимы (Этап 2)
├── risk.yaml                    # Параметры риска и ликвидности
├── simulation.yaml              # Monte Carlo и стресс-тесты
└── performance.yaml             # Производительность и кэширование
```
