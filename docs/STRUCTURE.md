# Структура проекта Equity Model

## Обзор

Проект использует структуру **src-layout** с разделением по функциональным модулям (10 этапов разработки).

```
equity-model/
├── src/equity_model/       # Исходный код пакета
├── tests/                  # Тесты
├── docs/                   # Документация
├── scripts/                # Скрипты запуска
├── config/                 # Конфигурация
├── data/                   # Данные (не версионируется)
├── .github/                # CI/CD workflows
└── ...                     # Конфигурационные файлы
```

---

## Основные директории

### `src/equity_model/` — Исходный код пакета

| Модуль | Этап | Описание |
| :--- | :---: | :--- |
| `__init__.py` | — | Публичный API пакета |
| `__version__.py` | — | Версия и метаданные |
| `data/` | 1 | Загрузка и обработка данных |
| `clustering/` | 2 | Кластеризация активов |
| `calibration/` | 3 | Калибровка параметров модели |
| `short_term/` | 4 | Краткосрочная модель (SMA) |
| `long_term/` | 5 | Долгосрочная модель (Марков) |
| `stress/` | 6 | Стресс-тестирование |
| `comparison/` | 7 | Сравнение моделей |
| `backtest/` | 8 | Бэктестирование и VaR тесты |
| `production/` | 9 | Оптимизация и пайплайны |
| `reporting/` | 10 | Отчётность и визуализация |
| `utils/` | — | Вспомогательные функции |

---

### `tests/` — Тесты

```
tests/
├── unit/           # Модульные тесты
├── integration/    # Интеграционные тесты
├── benchmarks/     # Тесты производительности
└── conftest.py     # Общие фикстуры pytest
```

| Тип тестов | Описание | Запуск |
| :--- | :--- | :--- |
| **unit/** | Тесты отдельных функций | `pytest tests/unit/` |
| **integration/** | Тесты взаимодействия модулей | `pytest tests/integration/` |
| **benchmarks/** | Тесты производительности | `pytest tests/benchmarks/ --benchmark-only` |

---

### `docs/` — Документация

```
docs/
├── index.md              # Главная страница
├── ROADMAP.md            # Дорожная карта
├── DEVELOPMENT_PLAN.md   # Детальный план 10 этапов
├── STRUCTURE.md          # Этот файл

├── methodology/          # Методология модели
└── reports/
    
```

---

### `scripts/` — Скрипты запуска

| Скрипт | Описание |
| :--- | :--- |
| `run_daily_pipeline.py` | Ежедневная симуляция |
| `run_quarterly_calibration.py` | Квартальная калибровка |
| `generate_reports.py` | Генерация отчётов |
| `update_cache.py` | Обновление кэша параметров |

**Запуск:**
```bash
uv run python scripts/run_daily_pipeline.py
```

---

### `config/` — Конфигурация

| Файл | Описание |
| :--- | :--- |
| `base.yaml` | Базовая конфигурация |
| `production.yaml` | Production настройки |
| `development.yaml` | Development настройки |
| `logging.yaml` | Настройки логирования |

---

### `data/` — Данные (не версионируется)

```
data/
├── raw/              # Исходные данные (игнорируется git)
├── processed/        # Обработанные данные (игнорируется git)
├── external/         # Внешние справочники (версионируется)
└── cache/            # Кэш параметров (версионируется частично)
```

**Важно:** В `.gitignore` добавлены `raw/` и `processed/`.

---

### `.github/` — CI/CD

```
.github/
└── workflows/
    ├── test.yml        # Запуск тестов
    ├── lint.yml        # Линтинг кода
    ├── docs.yml        # Деплой документации
    └── deploy.yml      # Деплой пакета
```
