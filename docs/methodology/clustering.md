## 1. Обзор

Кластеризация активов — второй этап проекта Equity Model. Модуль группирует инструменты по поведенческому сходству для построения иерархической корреляционной структуры.

**Ключевые особенности:**
- 4 активных рыночных режима (Bull/Bear × Low/High Vol)
- Архитектура поддерживает 9 режимов (для будущего расширения)
- Адаптивные методы корреляции для разных групп истории
- Квартальная перекластеризация (63 дня)
- Кризисный режим с заморозкой кластеров
- 16 unit-тестов с покрытием критической логики

## 2. Классификация входных данных

### 2.1. Группы по длине истории

Активы распределяются по 4 группам на основе количества доступных торговых дней до текущей даты:

| Группа | Диапазон дней | Метод корреляции | Консервативный множитель (β/σ) |
| :--- | :--- | :--- | :--- |
| **A** | 0–30 | Секторный прокси + рынок | 1.30 / 1.20 |
| **B** | 30–100 | Расстояние Вассерштейна | 1.20 / 1.10 |
| **C** | 100–200 | Pearson SMA (окно 50) | 1.05 / 1.05 |
| **D** | 200+ | Pearson EWMA (λ=0.94) | 1.00 / 1.00 |

**Обоснование:** Группа D служит эталоном. Кластеры групп A, B, C маппятся на кластеры группы D для обеспечения согласованности.

### 2.2. Группы по ликвидности

Коэффициент ликвидности рассчитывается как:

$$ \text{Liquidity Ratio} = \frac{\text{Торговых дней с данными}}{\text{Календарных дней в периоде}} $$

| Класс | Порог | Обработка |
| :--- | :--- | :--- |
| **Ликвидные** | ≥ 0.80 | Стандартная обработка |
| **Неликвидные** | < 0.80 | Импутация через Market Model + премия к волатильности |

**Премия за ликвидность:**

| Liquidity Ratio | Multiplier |
| :--- | :--- |
| ≥ 0.80 | 1.0 |
| 0.60–0.80 | 1.2 |
| 0.40–0.60 | 1.5 |
| < 0.40 | 2.0 |

## 3. Определение рыночного режима

Система использует матрицу 2×2 (Направление × Волатильность) для определения 4 активных режимов Production.

### 3.1. Score направления (0.0–1.0)

Взвешенная сумма 5 индикаторов:

| Индикатор | Вес | Bull порог | Bear порог |
| :--- | :--- | :--- | :--- |
| Цена vs SMA-200 | 0.30 | 1.05 | 0.95 |
| SMA-50 vs SMA-200 | 0.20 | 1.02 | 0.98 |
| Ширина рынка | 0.20 | 0.60 | 0.40 |
| Объем/Волатильность | 0.15 | 1.20 | 0.80 |
| Макро-тренд | 0.15 | 0.60 | 0.40 |

**Пороги режимов:**
- **Bull:** Score ≥ 0.60
- **Bear:** Score ≤ 0.40
- **Neutral:** 0.40–0.60 (маппится на ближайший активный режим)

### 3.2. Score волатильности (0.0–1.0)

Взвешенная комбинация:
- **VIX-RUS:** вес 0.60 (пороги: Low < 20, High > 35)
- **Историческая волатильность IMOEX:** вес 0.40 (пороги: Low < 15%, High > 25%)

**Классификация:**
- **Low Vol:** Score ≤ 0.33
- **Normal Vol:** 0.33–0.67 (маппится на Low/High)
- **High Vol:** Score ≥ 0.67

### 3.3. Гистерезис

Для предотвращения ложных переключений требуется **3 дня подряд** с одинаковым направлением для подтверждения смены режима.

### 3.4. Активные режимы Production

| Режим | Направление | Волатильность | Drift Mult | Sigma Mult | Corr Adj | Haircut |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **BULL_LOW** | Bull | Low | 1.20 | 0.80 | -0.10 | 0.90 |
| **BULL_HIGH** | Bull | High | 0.80 | 1.30 | +0.15 | 1.20 |
| **BEAR_LOW** | Bear | Low | 0.70 | 1.00 | +0.10 | 1.10 |
| **BEAR_HIGH** | Bear | High | 0.50 | 1.50 | +0.25 | 1.50 |

> **Примечание:** Режимы NEUTRAL_* существуют в архитектуре (9 режимов), но не активны в Production.

## 4. Построение матриц корреляций

### 4.1. Методы по группам

**Группа D (EWMA):**
$$ \text{Cov}_{t} = \lambda \cdot \text{Cov}_{t-1} + (1-\lambda) \cdot (r_{t} - \bar{r})(r_{t} - \bar{r})^{T} $$
где λ = 0.94 (стандарт RiskMetrics), окно = 504 дня.

**Группа C (SMA):**
$$ \rho = \frac{\sum_{i=1}^{n}(x_{i} - \bar{x})(y_{i} - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_{i} - \bar{x})^{2}}\sqrt{\sum_{i=1}^{n}(y_{i} - \bar{y})^{2}}} $$
окно = 50 дней.

**Группа B (Wasserstein):** - улавливает нелинейность и сдвиги распределений при малой выборке
$$ \text{Correlation} = 1 - \frac{W_{2}(P_{x}, P_{y})}{2} $$
где $W_{2}$ — расстояние Вассерштейна между нормализованными распределениями доходностей.

**Группа A (Секторный прокси):**
```
Если сектор одинаковый: base_corr = 0.70
Если сектор разный: base_corr = 0.50
С поправкой на корреляцию с рынком: corr = base × weight + 0.50 × (1 - weight)
```

### 4.2. Корректировки матрицы

1. **Режимная корректировка:**
   $$ \rho_{adjusted} = \text{clip}(\rho_{base} + \Delta_{regime}, -1.0, 1.0) $$

2. **Ограничение ликвидности:**
   Корреляция liquid-illiquid ограничивается сверху (cap = 0.75).

3. **Конвертация в расстояния:**
   $$ \text{Distance} = \sqrt{2 \times (1 - \text{Correlation})} $$

## 5. Алгоритм кластеризации

### 5.1. Метод

**Иерархическая агломеративная кластеризация** (Hierarchical Agglomerative Clustering):
- **Метрика:** Precomputed distance matrix
- **Linkage:** Average (среднее расстояние между всеми парами)
- **Диапазон K:** 2–15 кластеров

### 5.2. Оптимизация числа кластеров

Для каждого K рассчитываются:

| Метрика | Формула | Критерий |
| :--- | :--- | :--- |
| **Silhouette Score** | $(b - a) / \max(a, b)$ | Максимизировать (> 0.3) |
| **Davies-Bouldin Index** | Среднее сходство кластеров | Минимизировать |

**Правило выбора:**
1. Отфильтровать K с Silhouette < 0.3
2. Среди оставшихся выбрать K с минимальным Davies-Bouldin
3. Если все отфильтрованы — выбрать K ближайший к target (7)

### 5.3. Частота обновления

| Компонент | Частота | Триггер |
| :--- | :--- | :--- |
| **Кластеры** | Ежеквартально | 63 дня или force_recluster |
| **Параметры риска** | Ежедневно | Смена режима рынка |
| **Режим рынка** | Ежедневно | Новые данные IMOEX/VIX |

## 6. Маппинг кластеров

Так как Группа D имеет наиболее надёжную статистику, кластеры групп A, B, C согласуются с ней.

### 6.1. Алгоритм маппинга

1. Для каждой группы A/B/C строится своя матрица расстояний
2. Проводится независимая кластеризация
3. Для каждого кластера "малой" группы:
   - Вычисляются средние расстояния до всех кластеров Группы D
   - Выбирается кластер D с **минимальным средним расстоянием**
4. Активы "малой" группы получают метку выбранного кластера D

### 6.2. Гарантии

- Все активы имеют метку кластера из единого пространства
- Активы с короткой историей наследуют риск-профиль похожих активов с длинной историей
- При добавлении нового актива он автоматически маппится на существующие кластеры

## 7. Расчёт консервативных параметров риска

### 7.1. Формула

Для каждого актива $i$ в режиме $r$:

$$ \sigma_{adjusted} = \sigma_{base} \times M_{history} \times M_{regime} \times M_{liquidity} $$

$$ \beta_{adjusted} = \beta_{base} \times M_{history} $$

### 7.2. Множители

**История:**

| Группа | Beta Mult | Sigma Mult |
| :--- | :--- | :--- |
| A | 1.30 | 1.20 |
| B | 1.20 | 1.10 |
| C | 1.05 | 1.05 |
| D | 1.00 | 1.00 |

**Режим (пример BEAR_HIGH):**
- Sigma Multiplier: 1.50
- Haircut Multiplier: 1.50
- Correlation Adjustment: +0.25

**Ликвидность:** см. таблицу в разделе 2.2

## 8. Контроль устойчивости

### 8.1. Adjusted Rand Index (ARI)

Для оценки стабильности кластеризации во времени используется ARI (ARI исправляет случайные совпадения, в отличие от обычного Rand Index):

$$ \text{ARI} = \frac{\text{Index} - \text{Expected Index}}{\text{Max Index} - \text{Expected Index}} $$

**Пороги:**
- **ARI ≥ 0.7:** Кластеризация устойчива
- **ARI < 0.7:** Требуется анализ причин изменений

**Мониторинг:**
- Расчёт ARI между текущей и предыдущей кластеризацией
- Сохранение истории за 8 кварталов (2 года)
- Алерт при ARI < 0.5

### 8.2. Кризисный режим (Freeze)

**Триггеры (любой из трёх):**

| Триггер | Порог | Источник |
| :--- | :--- | :--- |
| VIX-RUS | > 40 | `crisis.vix_threshold` |
| Просадка IMOEX | < -20% | `crisis.imoex_drawdown` |
| Средняя корреляция | > 0.90 | `crisis.correlation_spike` |

**Действия при активации:**
1. Кластеризация замораживается на **63 дня**
2. Используются последние сохранённые кластеры
3. Параметры риска обновляются ежедневно (по режиму)
4. Все сигналы кризиса логируются

**Выход из кризиса:**
- Автоматически после истечения 63 дней
- Или вручную через `force_recluster=True`

## 9. Обработка неликвидных активов

### 9.1. Импутация пропусков

Для неликвидных активов с пропусками в данных применяется Market Model:

$$ r_{imputed} = \beta \times r_{market} $$

**Оценка Beta:**
- Регрессия доступных доходностей актива на доходности рынка
- Ограничение (clip): [0.5, 3.0]
- При недостатке данных: β = 1.0 (fallback)

### 9.2. Корректировка корреляций

Корреляции между ликвидными и неликвидными активами ограничиваются:
$$ \rho_{liquid-illiquid} = \min(\rho_{calculated}, 0.75) $$

**Обоснование:** Неликвидные активы имеют запаздывающие цены, что искусственно занижает корреляции.

## 13. Конфигурация

### 13.1. Основные параметры

```yaml
clustering:
  history_groups:
    A: {min_days: 0, max_days: 30, method: sector_proxy_market}
    B: {min_days: 30, max_days: 100, method: wasserstein}
    C: {min_days: 100, max_days: 200, method: pearson_sma}
    D: {min_days: 200, max_days: null, method: pearson_ewma}
  
  regimes:
    active: [BULL_LOW, BULL_HIGH, BEAR_LOW, BEAR_HIGH]
  
  correlation:
    ewma_lambda: 0.94
    ewma_window: 504
    sma_window: 50
    liquid_illiquid_cap: 0.75
  
  clustering:
    k_min: 2
    k_max: 15
    k_target: 7
    ari_threshold: 0.7
    silhouette_threshold: 0.3
    recluster_frequency_days: 63
  
  liquidity:
    threshold: 0.80
    imputation_beta_clip: [0.5, 3.0]
    liquidity_premium: {0.80: 1.0, 0.60: 1.2, 0.40: 1.5, 0.0: 2.0}
  
  crisis:
    vix_threshold: 40
    imoex_drawdown: -0.20
    correlation_spike: 0.90
    freeze_duration_days: 63
```

### 13.2. Переопределение параметров

Параметры могут быть переопределены через:
1. YAML-файл конфигурации
2. Переменные окружения
3. Прямую передачу в конструктор `AssetClustering(config=...)`

## 14. Мониторинг Production

### 14.1. Алерты

| Событие | Уровень | Действие |
| :--- | :--- | :--- |
| Переход в BEAR_HIGH | Warning | Уведомление риск-менеджеру |
| Активация кризиса | Critical | Уведомление + логирование |
| ARI < 0.5 | Warning | Анализ стабильности |
| Время выполнения > 2ч | Warning | Оптимизация кода |
| Ошибка кластеризации | Critical | Fallback на предыдущие кластеры |

### 14.2. Метрики для дашборда

- Текущий режим рынка
- Количество кластеров по группам
- ARI за последние 8 кварталов
- Доля неликвидных активов
- Время последнего запуска

## 15. Ограничения и допущения

| Ограничение | Влияние | Митигация |
| :--- | :--- | :--- |
| Нормальность доходностей | Недооценка хвостов | Jump-процесс в симуляции |
| Стационарность β внутри режима | Ошибки при сдвигах | Ежедневное обновление параметров |
| История < 30 дней | Низкая надёжность | Консервативные множители |
| Квартальная перекластеризация | Запаздывание при шоках | Кризисный freeze |
| Упрощённая ликвидность | Риск при замораживании | Liquidity premium + haircut |
