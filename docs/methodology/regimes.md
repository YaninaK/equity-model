## 1. Обзор

Система рыночных режимов — ключевой компонент Equity Model, обеспечивающий адаптацию параметров риска к текущему состоянию рынка.

**Архитектура:**
- **9 режимов** - матрица 3×3: Direction × Volatility
- **4 активных режима** для Production - Bull/Bear × Low/High
- **Multi-Indicator Detector** - 5 индикаторов направления
- **Volatility Overlay** - VIX-RUS (или RVI https://www.moex.com/ru/index/RVI) + историческая волатильность
- **Кризисный режим** с заморозкой кластеров
- **Цепь Маркова** для переключения режимов в симуляции

## 2. Матрица режимов

### 2.1. Полная матрица 3×3 (9 состояний)

| Direction / Vol | Low Vol | Normal Vol | High Vol |
| :--- | :--- | :--- | :--- |
| **Bull** | BULL_LOW | BULL_NORMAL | BULL_HIGH |
| **Neutral** | NEUTRAL_LOW | NEUTRAL_NORMAL | NEUTRAL_HIGH |
| **Bear** | BEAR_LOW | BEAR_NORMAL | BEAR_HIGH |

### 2.2. Активные режимы Production (4 из 9)

Для промышленной эксплуатации активированы 4 режима:

| Режим | Направление | Волатильность | Статус |
| :--- | :--- | :--- | :--- |
| **BULL_LOW** | Bull | Low | Active |
| **BULL_HIGH** | Bull | High | Active |
| **BEAR_LOW** | Bear | Low | Active |
| **BEAR_HIGH** | Bear | High | Active |
| BULL_NORMAL | Bull | Normal | Reserved |
| NEUTRAL_* | Neutral | * | Reserved |
| BEAR_NORMAL | Bear | Normal | Reserved |

**Обоснование:** Neutral и Normal режимы маппятся на ближайшие активные для упрощения Production.

## 3. Multi-Indicator Detector (Направление рынка)

### 3.1. Индикаторы и веса

| № | Индикатор | Вес | Порог Bull | Порог Bear | Источник |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | Цена vs SMA-200 | 30% | > 1.05 | < 0.95 | IMOEX |
| 2 | SMA-50 vs SMA-200 | 20% | > 1.02 | < 0.98 | IMOEX |
| 3 | Ширина рынка | 20% | > 60% | < 40% | MOEX (все акции) |
| 4 | Объём торгов | 15% | > 1.2× медианы | < 0.8× медианы | MOEX Turnover |
| 5 | Макро-индикаторы | 15% | Положительные | Отрицательные | ЦБ РФ, Росстат |

### 3.2. Формула расчёта Score

$$ \text{Direction\_Score} = \sum_{i=1}^{5} (\text{Indicator\_Value}_i \times \text{Weight}_i) $$

**Нормализация индикаторов в диапазон [0.0, 1.0]:**

**Индикатор 1: Цена vs SMA-200**
```
Значение = (Текущая цена IMOEX / SMA-200) - 1

Если > 0.05  →  1.0 (сильный Bull)
Если < -0.05 →  0.0 (сильный Bear)
Иначе        →  линейная интерполяция
```

**Индикатор 2: SMA-50 vs SMA-200**
```
Значение = (SMA-50 / SMA-200) - 1

Если > 0.02  →  1.0 (Bull)
Если < -0.02 →  0.0 (Bear)
Иначе        →  линейная интерполяция
```

**Индикатор 3: Ширина рынка**
```
Значение = (% акций MOEX выше SMA-50) / 100

Если > 60%  →  1.0 (Bull)
Если < 40%  →  0.0 (Bear)
Иначе       →  линейная интерполяция
```

**Индикатор 4: Объём торгов**
```
Значение = (20-дневный средний объём / 200-дневная медиана)

Если > 1.2  →  1.0 (высокий объём = Bull)
Если < 0.8  →  0.0 (низкий объём = Bear)
Иначе       →  линейная интерполяция
```

**Индикатор 5: Макро-индикаторы**
```
Компоненты:
  - Ключевая ставка ЦБ (снижение = Bull)
  - Инфляция (в целевом диапазоне = Bull)
  - ВВП (рост = Bull)
  - Промышленное производство (рост = Bull)

Значение = Среднее по всем компонентам [0.0, 1.0]
```

### 3.3. Определение направления

| Direction_Score | Режим | Интерпретация |
| :--- | :--- | :--- |
| > 0.60 | **Bull** | Бычий рынок |
| 0.40 – 0.60 | **Neutral** | Неопределённость |
| < 0.40 | **Bear** | Медвежий рынок |

### 3.4. Гистерезис

Для предотвращения ложных переключений требуется устойчивое подтверждение сигнала:

```
hysteresis_days = 3 (конфигурируемый параметр)

Требуется N дней подряд с одинаковым направлением
для подтверждения смены режима
```

**Алгоритм:**
1. Ежедневный расчёт Direction_Score
2. Сохранение истории последних N дней
3. Если все N дней = Bull → подтверждение Bull
4. Если все N дней = Bear → подтверждение Bear
5. Иначе → Neutral или сохранение предыдущего режима

## 4. Volatility Overlay (Уровень волатильности)

### 4.1. Уровни волатильности

| Уровень | VIX-RUS | Историческая Vol (20д) | Параметры модели |
| :--- | :--- | :--- | :--- |
| **Low Vol** | < 20 | < 15% | Стандартные |
| **Normal Vol** | 20–35 | 15–25% | Базовые |
| **High Vol** | > 35 | > 25% | Консервативные (+20% к VaR) |

### 4.2. Формула расчёта Score

$$ \text{Vol\_Score} = 0.60 \times \text{VIX\_Normalized} + 0.40 \times \text{Hist\_Vol\_Normalized} $$

**Нормализация VIX-RUS:**
```
Если VIX ≤ 10  →  0.0
Если VIX ≥ 50  →  1.0
Иначе          →  линейная интерполяция [(VIX - 10) / 40]
```

**Нормализация Исторической Vol:**
```
Если Vol ≤ 10%  →  0.0
Если Vol ≥ 40%  →  1.0
Иначе           →  линейная интерполяция [(Vol - 10%) / 30%]
```

### 4.3. Классификация волатильности

| Vol_Score | Уровень | Интерпретация |
| :--- | :--- | :--- |
| ≤ 0.33 | **Low** | Спокойный рынок |
| 0.33 – 0.67 | **Normal** | Базовая волатильность |
| ≥ 0.67 | **High** | Кризис, стресс |

### 4.4. Влияние на модель

| Режим Vol | GARCH параметры | Liquidity Premium | VaR Adjustment |
| :--- | :--- | :--- | :--- |
| Low | α=0.08, β=0.90 | × 1.0 | × 1.0 |
| Normal | α=0.10, β=0.85 | × 1.0 | × 1.0 |
| High | α=0.15, β=0.80 | × 1.2 | × 1.2 |

## 6. Интеграция с Monte Carlo симуляцией

### 6.1. Влияние режимов на параметры симуляции

**На момент T=0 (калибровка):**
1. Multi-Indicator Score → определить Bull/Bear/Neutral
2. Volatility Overlay → определить Low/Normal/High Vol
3. Выбрать параметры (μ, σ, корреляции) для текущего режима
4. Оценить вероятности перехода P(Bull → Bear), P(Bear → Bull)

**В симуляции (для каждого дня t):**
```
1. Проверить переключение режима (цепь Маркова)
2. Применить параметры текущего режима:
   - μ_t = drift[текущий_режим]
   - σ_t = volatility[текущий_режим] × vol_overlay_multiplier
   - Corr_t = base_correlation × correlation_adjustment[режим]
3. Сгенерировать коррелированные шоки
4. Рассчитать доходности: R_t = μ_t + σ_t × Z_corr
5. Обновить цены: S_t = S_{t-1} × exp(R_t)
```

### 6.2. Вероятности перехода (цепь Маркова)

| Переход | Вероятность (в день) | Вероятность (в год) |
| :--- | :--- | :--- |
| Bull → Bull | 98–99% | – |
| Bull → Bear | 1–2% | 30–50% |
| Bear → Bear | 95–98% | – |
| Bear → Bull | 2–5% | 50–80% |

**Калибровка:** Оценивается по историческим данным IMOEX (2014–2024)

### 6.3. Дрейф (μ) по режимам

| Режим | Дневной дрейф | Годовой дрейф | Обоснование |
| :--- | :--- | :--- | :--- |
| **Bull** | +0.03% до +0.08% | +8% до +20% | Рынок растёт |
| **Neutral** | -0.01% до +0.03% | -2% до +8% | Неопределённость |
| **Bear** | -0.05% до -0.01% | -12% до -2% | Рынок падает |

### 6.4. Волатильность (σ) по режимам

| Уровень Vol | Множитель к σ | Обоснование |
| :--- | :--- | :--- |
| **Low Vol** (VIX-RUS < 20) | × 0.8 | Спокойный рынок |
| **Normal Vol** (VIX 20–35) | × 1.0 | Базовый сценарий |
| **High Vol** (VIX > 35) | × 1.3 до 1.5 | Кризис, стресс |

### 6.5. Корреляции по комбинациям режимов

| Комбинация | Влияние на корреляции | Обоснование |
| :--- | :--- | :--- |
| Bull + Low Vol | Базовые корреляции | Диверсификация работает |
| Bull + High Vol | +0.10 к корреляциям | Напряжённость растёт |
| Bear + Normal Vol | +0.15 к корреляциям | Кризисные корреляции |
| Bear + High Vol | +0.25 к корреляциям | "Все падают вместе" |

## 7. Кризисный режим (Freeze)

### 7.1. Триггеры активации

Кризисный режим активируется при выполнении **любого** из трёх условий:

| Триггер | Порог | Источник |
| :--- | :--- | :--- |
| **VIX-RUS** | > 40 | `crisis.vix_threshold` |
| **Просадка IMOEX** | < -20% | `crisis.imoex_drawdown` |
| **Средняя корреляция** | > 0.90 | `crisis.correlation_spike` |

### 7.2. Действия при активации

1. Кластеризация замораживается на **63 дня**
2. Используются последние сохранённые кластеры
3. Параметры риска обновляются ежедневно (по режиму)
4. Все сигналы кризиса логируются для аудита

### 7.3. Выход из кризиса

- **Автоматически:** После истечения 63 дней
- **Вручную:** Через `force_recluster=True`

### 7.4. Исторические примеры (2014–2024)

| Период | Режим | VIX-RUS | IMOEX vs SMA200 | Корреляции |
| :--- | :--- | :--- | :--- | :--- |
| 2014 (Крым) | Bear + High Vol | 45–60 | -25% | +0.30 к базе |
| 2020 (COVID) | Bear + High Vol | 50–80 | -35% | +0.35 к базе |
| 2022 (СВО) | Bear + High Vol | 60–100 | -50% | +0.40 к базе |
| 2023–2024 | Neutral + Normal | 25–35 | ±5% | База |

## 9. Логирование для аудита

Для каждого расчёта сохраняются:

1. Дата и время расчёта
2. Значения всех 5 индикаторов
3. Volatility Overlay уровень
4. Итоговый режим (Direction + Vol)
5. Версия конфигурации
6. Сигналы кризиса (если активирован)

## 10. Влияние на метрики риска

### 10.1. VaR с режимами vs без режимов

| Метрика | Без режимов | С режимами | Разница |
| :--- | :--- | :--- | :--- |
| **VaR (95%)** | -35% | -42% | +20% |
| **VaR (99%)** | -50% | -62% | +24% |
| **Макс. просадка** | -45% | -58% | +29% |

**Почему выше:** Режимы учитывают кризисные периоды с высокими корреляциями.

### 10.2. PFE с режимами (согласно PFE Methodology)

```
PFE(T=252 дня, λ=95%) = q_0.95(V_1(T), ..., V_1000(T))

Без режимов: PFE = 1.35 × начальная стоимость
С режимами:  PFE = 1.52 × начальная стоимость (+13%)
```

### 10.3. Соответствие PFE Methodology

| Раздел | Требование | Реализация |
| :--- | :--- | :--- |
| 1.1 PFE(T,λ) | Monte Carlo с режимами | 9 режимов |
| 1.2 EAD | EAD(T) = α × max EPE(T), α=1.4 | Применять к максимальному exposure |
| 3.4.1 MR(T)* | MRRl из MarketRiskNCC | Vol Overlay влияет на MRR |
| 3.4.2 PR(T)* | Процентный риск | High Vol → консервативные ставки |

## 11. Production considerations

### 11.1. Алерты мониторинга

| Событие | Уровень | Действие |
| :--- | :--- | :--- |
| Переход в BEAR_HIGH | Warning | Уведомление риск-менеджеру |
| Активация кризиса | Critical | Уведомление + логирование |
| ARI < 0.5 | Warning | Анализ стабильности |
| Время выполнения > 2ч | Warning | Оптимизация кода |
| Ошибка кластеризации | Critical | Fallback на предыдущие кластеры |

### 11.2. Метрики для дашборда

- Текущий режим рынка
- Direction_Score и Vol_Score
- История переключений режимов (последние 90 дней)
- Дней в кризисном режиме
- Время до выхода из freeze

| Ограничение | Влияние | Митигация |
