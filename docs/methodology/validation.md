## 3. Walk-Forward валидация

### 3.1. Параметры

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Начальная дата** | T-335 дней | Минимум для калибровки |
| **Шаг** | 30 дней | Ежемесячная переоценка |
| **Количество итераций** | 8–10 | Статистическая значимость |
| **Горизонты прогноза** | 30, 60, 90 дней | Краткосрочное планирование |
| **Доверительный уровень** | 95%, 99% | Соответствие PFE Methodology |

### 3.2. Схема Walk-Forward

```
Итерация 1: [T-335 → T-252] калибровка → [T-252 → T-222] прогноз (30 дней)
Итерация 2: [T-305 → T-222] калибровка → [T-222 → T-192] прогноз (30 дней)
Итерация 3: [T-275 → T-192] калибровка → [T-192 → T-162] прогноз (30 дней)
...
Итерация 8: [T-125 → T-52]  калибровка → [T-52 → T-22]  прогноз (30 дней)
```

### 3.3. Метрики качества

| Метрика | Формула | Целевое значение | Порог тревоги |
| :--- | :--- | :--- | :--- |
| **Coverage Rate (90% CI)** | % наблюдений в интервале | > 85% | < 80% |
| **Coverage Rate (95% CI)** | % наблюдений в интервале | > 90% | < 85% |
| **MAE (Mean Absolute Error)** | Среднее \|факт - прогноз\| | < 5% | > 10% |
| **RMSE (Root Mean Square Error)** | √(среднее (ошибка²)) | < 7% | > 15% |
| **Bias** | среднее (прогноз - факт) | ≈ 0% | > ±3% |

### 3.4. Критерии прохождения

```python
def validate_walk_forward(results):
    """Валидация Walk-Forward результатов."""
    
    criteria = {
        'coverage_90': results['coverage_90'] > 0.85,
        'coverage_95': results['coverage_95'] > 0.90,
        'mae': results['mae'] < 0.05,
        'rmse': results['rmse'] < 0.07,
        'bias': abs(results['bias']) < 0.03
    }
    
    passed = sum(criteria.values()) / len(criteria)
    
    if passed >= 0.80:
        return 'PASS', criteria
    elif passed >= 0.60:
        return 'WARNING', criteria
    else:
        return 'FAIL', criteria
```

## 4. VaR Backtesting

### 4.1. Тест Купиека (Unconditional Coverage)

**Формула:**
$$ LR_{uc} = -2 \times \ln\left((1-\alpha)^{N-x} \times \alpha^x\right) + 2 \times \ln\left((1-\frac{x}{N})^{N-x} \times (\frac{x}{N})^x\right) $$

**Где:**
| Параметр | Описание |
| :--- | :--- |
| **α** | Доверительный уровень (0.01 или 0.05) |
| **N** | Количество наблюдений |
| **x** | Количество нарушений (VaR exceedances) |

**Распределение:** $LR_{uc} \sim \chi^2(1)$

**Критерий:** p-value > 0.05

### 4.2. Тест Кристофферсена (Independence)

**Формула:**
$$ LR_{ind} = -2 \times \ln\left(\frac{L(\Pi_0)}{L(\Pi_1)}\right) $$

**Где:**
- $\Pi_0$ — матрица переходов при независимости
- $\Pi_1$ — наблюдаемая матрица переходов

**Распределение:** $LR_{ind} \sim \chi^2(1)$

**Критерий:** p-value > 0.05

### 4.3. Тест условного покрытия (Conditional Coverage)

**Формула:**
$$ LR_{cc} = LR_{uc} + LR_{ind} $$

**Распределение:** $LR_{cc} \sim \chi^2(2)$

**Критерий:** p-value > 0.05

### 4.4. Требования PFE Methodology

| Раздел | Требование | Реализация | Статус |
| :--- | :--- | :--- | :--- |
| **1.1 PFE(T, λ)** | Квантиль распределения | 95-й перцентиль из 10 000 путей | ✅ |
| **1.2 EAD** | EAD = α × max EPE, α = 1.4 | Применяется к максимальному exposure | ✅ |
| **1.2.1 EPE** | EPE = среднее по симуляциям | Среднее по всем 10 000 путей | ✅ |
| **3.4.1 MR(T)*** | Haircuts по Vol Overlay | Динамические haircuts | ✅ |
| **3.4.2 PR(T)*** | Процентный риск | High Vol → консервативные ставки | ✅ |

## 6. Валидация устойчивости кластеризации

### 6.1. Adjusted Rand Index (ARI)

**Формула:**
$$ \text{ARI} = \frac{\text{Index} - \text{Expected Index}}{\text{Max Index} - \text{Expected Index}} $$

**Интерпретация:**
| ARI | Интерпретация | Действие |
| :--- | :--- | :--- |
| **≥ 0.7** | Высокая устойчивость | Норма |
| **0.5 – 0.7** | Умеренная устойчивость | Мониторинг |
| **< 0.5** | Низкая устойчивость | Алерт, анализ |

### 6.2. Мониторинг по кварталам

```

```

### 7.2. Гистерезис тест

```python
def test_hysteresis(regime_history, hysteresis_days=3):
    """Проверка гистерезиса режимов."""
    
    false_switches = 0
    total_switches = 0
    
    for i in range(hysteresis_days, len(regime_history)):
        window = regime_history[i-hysteresis_days:i]
        current = regime_history[i]
        
        if len(set(window)) > 1:  # Неустойчивый сигнал
            if current != regime_history[i-1]:
                false_switches += 1
        total_switches += 1
    
    false_rate = false_switches / max(total_switches, 1)
    
    return false_rate < 0.10  # < 10% ложных переключений
```
