## 1. Что даёт GARCH(1,1)?

### 1.1. Оцениваемые параметры

Для каждого уровня волатильности (Low/Normal/High) GARCH(1,1) оценивает три параметра:

| Параметр | Название | Смысл | Единицы | Диапазон |
| :--- | :--- | :--- | :--- | :--- |
| **ω (omega)** | Константа | Базовый уровень волатильности (долгосрочная средняя) | **Годовая дисперсия** | 0.02 – 0.10 |
| **α (alpha)** | Коэффициент ARCH | Влияние вчерашнего шока на сегодняшнюю волатильность | Безразмерный | 0.05 – 0.20 |
| **β (beta)** | Коэффициент GARCH | Персистентность волатильности (как долго сохраняется эффект) | Безразмерный | 0.75 – 0.95 |

**Уравнение модели:**

$$ \sigma_t^2 = \omega + \alpha \cdot \epsilon_{t-1}^2 + \beta \cdot \sigma_{t-1}^2 $$

**Где:**
| Переменная | Описание | Единицы |
| :--- | :--- | :--- |
| $\sigma_t^2$ | Условная дисперсия на день t | Годовая дисперсия |
| $\epsilon_{t-1}$ | Стандартизированный остаток (инновация) | Безразмерный |
| $\sigma_{t-1}^2$ | Условная дисперсия предыдущего дня | Годовая дисперсия |

**Условие стационарности:**

$$ \alpha + \beta < 1 $$

---

### 1.2. Прогноз волатильности

Используя оценённые параметры, мы можем прогнозировать волатильность на будущие периоды:

$$ \mathbb{E}[\sigma_{t+h}^2 | \mathcal{F}_t] = \frac{\omega}{1 - \alpha - \beta} + (\alpha + \beta)^{h} \left( \sigma_t^2 - \frac{\omega}{1 - \alpha - \beta} \right) $$

**Где:**
| Параметр | Описание |
| :--- | :--- |
| $h$ | Горизонт прогноза (дней) |
| $\frac{\omega}{1 - \alpha - \beta}$ | Долгосрочная средняя дисперсия |
| $(\alpha + \beta)^h$ | Скорость затухания шока |

**При $h \to \infty$** прогноз стремится к долгосрочной средней волатильности $\sqrt{\frac{\omega}{1 - \alpha - \beta}}$.

---

### 1.3. Параметры GARCH по уровням волатильности

| Уровень волатильности | α (ARCH) | β (GARCH) | ω (Constant) | α+β | Долгосрочная σ (годовая) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Low Vol** | 0.08 | 0.90 | 0.02 | 0.98 | √(0.02/0.02) = 100% |
| **Normal Vol** | 0.10 | 0.85 | 0.05 | 0.95 | √(0.05/0.05) = 100% |
| **High Vol** | 0.15 | 0.80 | 0.10 | 0.95 | √(0.10/0.05) = 141% |

> **Примечание:** Параметры ω указаны в **годовой дисперсии**. Для конвертации в дневную:
> $$ \omega_{daily} = \omega_{annual} / 252 $$
> $$ \sigma_{daily} = \sigma_{annual} / \sqrt{252} $$

## 2. Интеграция GARCH с режимами рынка (Этап 2)

### 2.1. Маппинг 4 режимов → 3 уровня GARCH

В Этапе 2 определены **4 активных режима** (BULL_LOW, BULL_HIGH, BEAR_LOW, BEAR_HIGH), но GARCH калибруется по **3 уровням волатильности**.

| Режим (Этап 2) | Направление | Волатильность | GARCH уровень |
| :--- | :--- | :--- | :--- |
| **BULL_LOW** | Bull | Low | **Low Vol GARCH** |
| **BULL_HIGH** | Bull | High | **High Vol GARCH** |
| **BEAR_LOW** | Bear | Low | **Low Vol GARCH** |
| **BEAR_HIGH** | Bear | High | **High Vol GARCH** |
| **NEUTRAL_*** | Neutral | Normal | **Normal Vol GARCH** (fallback) |

**Обоснование:** Волатильность не зависит от направления рынка (Bull/Bear), только от уровня стресса (Low/High).

---

### 2.2. Параметры режимов для симуляции

| Режим | Дрейф (μ) | σ множитель | GARCH уровень | Corr adjustment |
| :--- | :--- | :--- | :--- | :--- |

| **BULL_HIGH** | +0.03% / день | 1.30× | High Vol | +0.15 |
| **BEAR_LOW** | -0.02% / день | 1.00× | Low Vol | +0.10 |

## 3. Использование GARCH в Monte Carlo симуляции (Этап 4)

### 3.1. Алгоритм симуляции для одного пути

#### **Шаг 0. Инициализация (T=0)**

Для каждого пути $m = 1$ до $M$ (10 000 путей):

| Параметр | Значение | Источник |
| :--- | :--- | :--- |
| **$\sigma_{0,m}^2$** | $\omega_r / (1 - \alpha_r - \beta_r)$ | Долгосрочная средняя текущего режима |
| **$\epsilon_{0,m}$** | $Z \sim N(0, 1)$ | Случайная инициализация |
| **$S_{0,m}$** | $S_{last\_historical}$ | Последняя историческая цена |
| **Режим $r_0$** | Из RegimeDetector (Этап 2) | Multi-Indicator + Vol Overlay |

**Код:**
```python
# Инициализация для каждого пути
sigma2_0 = omega[regime] / (1 - alpha[regime] - beta[regime])
epsilon_0 = np.random.normal(0, 1)
S_0 = prices.iloc[-1]  # Последняя историческая цена
```

---

#### **Шаг 1. Переключение режимов (цепь Маркова)**

Для каждого дня $t = 1$ до $T$:

```python
# Проверка переключения режима
if current_regime == 'BULL':
    if np.random.random() < P(Bull → Bear):  # 1-2% в день
        current_regime = 'BEAR'
elif current_regime == 'BEAR':
    if np.random.random() < P(Bear → Bull):  # 2-5% в день
        current_regime = 'BULL'

# Определение уровня волатильности
vol_level = get_vol_level(current_regime)  # Low/High → GARCH параметры
```

**Матрица переходов:**
| Переход | Вероятность (в день) | Вероятность (в год) |
| :--- | :--- | :--- |
| Bull → Bull | 98–99% | – |
| Bull → Bear | 1–2% | 30–50% |
| Bear → Bear | 95–98% | – |
| Bear → Bull | 2–5% | 50–80% |

---

#### **Шаг 2. Применение GARCH для текущего режима**

**Важно:** При переключении режима $\sigma_{t-1}$ **сохраняется** (непрерывность волатильности), но параметры $\alpha, \beta, \omega$ меняются на параметры нового режима.

```python
# Выбор параметров GARCH для текущего режима
alpha_r = GARCH_PARAMS[vol_level]['alpha']
beta_r = GARCH_PARAMS[vol_level]['beta']
omega_r = GARCH_PARAMS[vol_level]['omega']

# Вычисление условной дисперсии
sigma2_t = omega_r + alpha_r * (epsilon_{t-1} ** 2) + beta_r * sigma2_{t-1}
sigma_t = np.sqrt(sigma2_t)
```

**Формула:**
$$ \sigma_t^2 = \omega_r + \alpha_r \cdot \epsilon_{t-1}^2 + \beta_r \cdot \sigma_{t-1}^2 $$

---

#### **Шаг 3. Генерация коррелированных доходностей**

```python
# Генерация коррелированных шоков
Z = np.random.normal(0, 1, size=n_assets)  # Независимые шоки
Z_corr = L @ Z  # Разложение Холецкого: L @ L.T = correlation_matrix

# Корректировка корреляций по режиму (АДДИТИВНАЯ)
# ρ_adjusted = ρ_base + Δ_regime (не ρ_base × Δ_regime!)
corr_adjusted = corr_base + regime_params['correlation_adjustment']
corr_adjusted = np.clip(corr_adjusted, -1.0, 1.0)
L = cholesky(corr_adjusted)  # Пересчёт разложения Холецкого

# Расчёт доходностей для каждого актива i
r_{i,t} = μ_{i,r} + σ_{i,t} × Z_corr[i]

# Где:
# μ_{i,r} = drift_multiplier[regime] × base_drift[i]
# σ_{i,t} = sigma_t × M_history[i] × M_liquidity[i]
```

**Применение консервативных множителей:**
$$ \sigma_{i,t}^{adjusted} = \sigma_t \times M_{history,i} \times M_{liquidity,i} $$

| Группа истории | $M_{history}$ (Beta) | $M_{history}$ (Sigma) |
| :--- | :--- | :--- |
| A (0–30 дней) | 1.30 | 1.20 |
| B (30–100 дней) | 1.20 | 1.10 |
| C (100–200 дней) | 1.05 | 1.05 |
| D (200+ дней) | 1.00 | 1.00 |

---

#### **Шаг 4. Обновление цен и переход к следующему дню**

```python
# Обновление цен
S_{i,t} = S_{i,t-1} × exp(r_{i,t})

# Сохранение инновации для следующего шага GARCH
epsilon_{i,t} = (r_{i,t} - μ_{i,r}) / σ_{i,t}

# Переход к t+1
sigma2_{t-1} = sigma2_t
epsilon_{t-1} = epsilon_t
```

### 3.2. Агрегация результатов (10 000 путей)

После генерации $M$ траекторий для каждого дня горизонта:

| Метрика | Формула | Использование |
| :--- | :--- | :--- |
| **VaR (95%)** | 5-й перцентиль распределения $V_m(T)$ | Лимиты риска |
| **VaR (99%)** | 1-й перцентиль распределения $V_m(T)$ | Стресс-лимиты |

### 3.3. Пример расчёта (числовой)

**Входные данные:**
- Режим: **Normal Vol** (α=0.10, β=0.85, ω=0.05)
- Текущая волатильность: $\sigma_{t-1} = 20\%$ годовых = $0.20$
- Вчерашний шок: $\epsilon_{t-1} = -1.5$ (доходность отклонилась на -1.5σ)
- Единицы: **годовая дисперсия**

**Расчёт:**
```python
# Конвертация в годовую дисперсию
sigma2_{t-1} = 0.20 ** 2 = 0.04  # Годовая дисперсия

# GARCH уравнение
sigma2_t = 0.05 + 0.10 × (-1.5) ** 2 + 0.85 × 0.04
sigma2_t = 0.05 + 0.10 × 2.25 + 0.85 × 0.04
sigma2_t = 0.05 + 0.225 + 0.034 = 0.309

# Волатильность
sigma_t = √0.309 = 0.556 = 55.6% годовых
```

**Интерпретация:** Волатильность выросла с 20% до 55.6% из-за большого вчерашнего шока.

**Конвертация в дневную волатильность:**
```python
sigma_daily = 55.6% / √252 = 3.5% в день
```

## 4. Преимущества использования GARCH в симуляции

| Преимущество | Описание | Влияние на метрики |
| :--- | :--- | :--- |
| **Кластеризация волатильности** | Периоды высокой волатильности сменяются периодами низкой | VaR (99%) +24% |
| **Адаптивность к режимам** | Параметры GARCH меняются с режимом волатильности | PFE +13% |
| **Прогноз на несколько шагов** | Формула прогноза позволяет моделировать волатильность на весь горизонт | Уменьшение ошибки прогноза |
| **Совместимость с иерархией** | GARCH применяется к рыночному фактору, активы получают долю через β и σ_idio | Согласованность уровней |

## 7. Технические спецификации

### 7.1. Инициализация симуляции

```python
def initialize_simulation(n_paths, regime_params, garch_params):
    """Инициализация параметров для каждого пути."""
    
    sigma2_0 = np.zeros(n_paths)
    epsilon_0 = np.zeros(n_paths)
    
    for m in range(n_paths):
        # Долгосрочная средняя для текущего режима
        omega = garch_params[regime]['omega']
        alpha = garch_params[regime]['alpha']
        beta = garch_params[regime]['beta']
        
        sigma2_0[m] = omega / (1 - alpha - beta)
        epsilon_0[m] = np.random.normal(0, 1)
    
    return sigma2_0, epsilon_0
```

### 7.2. Обработка переключения режимов

```python
def switch_regime(current_regime, transition_probs):
    """Переключение режима по цепи Маркова."""
    
    if current_regime == 'BULL':
        if np.random.random() < transition_probs['bull_to_bear']:
            return 'BEAR'
    elif current_regime == 'BEAR':
        if np.random.random() < transition_probs['bear_to_bull']:
            return 'BULL'
    
    return current_regime

# Важно: sigma_{t-1} сохраняется при переключении!
# Меняются только alpha, beta, omega
```

### 7.3. Корректировка корреляций

```python
def adjust_correlations(corr_matrix, regime_params):
    """Корректировка корреляций по режиму (АДДИТИВНАЯ)."""
    
    adjustment = regime_params.get('correlation_adjustment', 0.0)
    
    # ρ_adjusted = ρ_base + Δ_regime (не умножение!)
    corr_adjusted = corr_matrix + adjustment
    
    # Ограничение диапазона
    corr_adjusted = np.clip(corr_adjusted, -1.0, 1.0)
    
    # Диагональ = 1.0
    np.fill_diagonal(corr_adjusted, 1.0)
    
    return corr_adjusted
```
