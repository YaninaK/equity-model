## 1. Обзор модели

**Equity Model** — это иерархическая модель Монте-Карло для прогнозирования цен акций с учётом рыночных режимов (9 состояний, 4 активных), стресс-сценариев, инфляции и адаптивной кластеризации активов.

### 1.1. Назначение

- Краткосрочное прогнозирование (до 90 дней)
- Долгосрочное прогнозирование (до 40 лет)
- Оценка рыночных рисков (VaR, Expected Shortfall, PFE)
- Стресс-тестирование портфеля
- Расчёт лимитов (EAD, MR, PR)

### 1.2. Область применения

| Параметр | Значение |
| :--- | :--- |
| **Инструменты** | 260+ акций российского рынка (MOEX) |
| **Горизонты** | 1 день — 40 лет |
| **Частота обновления** | Ежедневно (прогноз, режимы), Ежеквартально (кластеры, калибровка) |
| **Количество траекторий** | 10 000 (база), 50 000+ (стресс-тесты) |

### 1.3. Архитектура пайплайна

```
┌─────────────────────────────────────────────────────────────────┐
│                    EQUITY MODEL PIPELINE                        │
├─────────────────────────────────────────────────────────────────┤
│  1. Data Layer       → Загрузка, очистка, валидация             │
│  2. Regime Layer     → Multi-Indicator + Volatility Overlay     │
│  3. Clustering Layer → Адаптивная кластеризация (4 группы)      │
│  4. Risk Layer       → Расчёт параметров (β, σ, Haircuts)       │
│  5. Simulation Layer → Монте-Карло с режимами (цепь Маркова)    │
│  6. Export Layer     → PFE, VaR, EAD, отчёты для регулятора     │
└─────────────────────────────────────────────────────────────────┘
```

## 2. Ключевые допущения

| Допущение | Описание | Риск при нарушении | Митигация |
| :--- | :--- | :--- | :--- |
| **Нормальность доходностей** | Внутри режима доходности ~ N(μ, σ²) | Недооценка хвостовых рисков | Jump-процесс, t-распределение (опционально) |
| **Стационарность β** | β не меняется внутри режима | Ошибки в кризисных периодах | Ежедневное обновление, консервативные множители |
| **Постоянство матрицы переходов** | P не меняется со временем | Структурные сдвиги в экономике | Проверка по десятилетиям, MS-AR |
| **Иерархическая структура** | 3 уровня корреляций (рынок → кластер → акция) | Упрощение зависимостей | Валидация на исторических данных, ARI тесты |
| **Обработка пропусков** | Импутация через Market Model для неликвидных | Искажение ликвидности | Liquidity Premium, фильтрация по ликвидности |
| **Кризисный режим** | Freeze кластеров на 63 дня при триггерах | Запаздывание реакции | Ежедневное обновление параметров риска |

## 3. Структура модели

### 3.1. Иерархия корреляций

```
Уровень 1: Рыночные корреляции (между кластерами)
    ↓
Уровень 2: Внутрикластерные корреляции
    ↓
Уровень 3: Индивидуальные параметры акций (β, σ_idio)
```

### 3.2. Формула сборки корреляции

Для акций i и j:

```
Если i, j в одном кластере k:
    ρ_ij = ρ_cluster(k) × β_i × β_j + Δ_regime

Если i, j в разных кластерах:
    ρ_ij = ρ_market × β_i × β_j + Δ_regime
```

**Где:**
| Параметр | Описание | Источник |
| :--- | :--- | :--- |
| **ρ_market** | Рыночная корреляция (режим-зависимая) | `regimes.md` |
| **ρ_cluster(k)** | Внутрикластерная корреляция для кластера k | `clustering.md` |
| **β_i, β_j** | Бета-коэффициенты акций | `risk_parameters.md` |
| **Δ_regime** | Корректировка по режиму (от -0.10 до +0.25) | `regimes.md` |

### 3.3. Адаптивные методы корреляций

| Группа истории | Дней | Метод корреляции | Обоснование |
| :--- | :--- | :--- | :--- |
| **A** | 0–30 | Секторный прокси + рынок | Недостаточно данных для статистики |
| **B** | 30–100 | Расстояние Вассерштейна | Сравнение распределений |
| **C** | 100–200 | Pearson SMA (окно 50) | Переходная группа |
| **D** | 200+ | Pearson EWMA (λ=0.94) | Эталонная группа |

## 4. Идентификация рыночных режимов

### 4.1. Матрица режимов 3×3 (9 состояний)

| Direction / Vol | Low Vol | Normal Vol | High Vol |
| :--- | :--- | :--- | :--- |
| **Bull** | BULL_LOW | BULL_NORMAL | BULL_HIGH |
| **Neutral** | NEUTRAL_LOW | NEUTRAL_NORMAL | NEUTRAL_HIGH |
| **Bear** | BEAR_LOW | BEAR_NORMAL | BEAR_HIGH |

**Активные режимы Production (4 из 9):**
- BULL_LOW, BULL_HIGH, BEAR_LOW, BEAR_HIGH
- Остальные 5 режимов — зарезервированы для будущего расширения

### 4.2. Multi-Indicator Detector (Направление рынка)

| Индикатор | Вес | Порог Bull | Порог Bear | Источник |
| :--- | :--- | :--- | :--- | :--- |
| Цена vs SMA-200 | 30% | > 1.05 | < 0.95 | IMOEX |
| SMA-50 vs SMA-200 | 20% | > 1.02 | < 0.98 | IMOEX |
| Ширина рынка | 20% | > 60% | < 40% | MOEX (все акции) |
| Объём торгов | 15% | > 1.2× медианы | < 0.8× медианы | MOEX Turnover |
| Макро-индикаторы | 15% | Положительные | Отрицательные | ЦБ РФ, Росстат |

**Формула:**
$$ \text{Direction\_Score} = \sum_{i=1}^{5} (\text{Indicator\_Value}_i \times \text{Weight}_i) $$

**Пороги:**
- **Bull:** Score ≥ 0.60
- **Bear:** Score ≤ 0.40
- **Neutral:** 0.40–0.60 (маппится на ближайший активный режим)

### 4.3. Volatility Overlay (Уровень волатильности)

```math
$$\displaystyle \text{Vol\_Score} = 0.60 \times \text{VIX\_Normalized} + 0.40 \times \text{Hist\_Vol\_Normalized}$$
```

| Уровень Vol | VIX-RUS | Историческая Vol (20д) | Параметры модели |
| :--- | :--- | :--- | :--- |
| **Low Vol** | < 20 | < 15% | Стандартные (σ × 0.8) |
| **Normal Vol** | 20–35 | 15–25% | Базовые (σ × 1.0) |
| **High Vol** | > 35 | > 25% | Консервативные (σ × 1.5) |

### 4.4. Гистерезис

Требуется **3 дня подряд** с одинаковым направлением для подтверждения смены режима (предотвращение ложных переключений).

### 4.5. Матрица переходов Маркова

Для долгосрочной модели режимы переключаются по цепи Маркова:

```
P = | P(Bull→Bull)    P(Bull→Bear)  |
    | P(Bear→Bull)   P(Bear→Bear)  |
```

| Переход | Вероятность (в день) | Вероятность (в год) |
| :--- | :--- | :--- |
| Bull → Bull | 98–99% | – |
| Bull → Bear | 1–2% | 30–50% |
| Bear → Bear | 95–98% | – |
| Bear → Bull | 2–5% | 50–80% |

## 5. Кластеризация активов

### 5.1. Классификация по истории и ликвидности

| Критерий | Группы | Пороги |
| :--- | :--- | :--- |
| **История** | A, B, C, D | 0–30, 30–100, 100–200, 200+ дней |
| **Ликвидность** | Liquid / Illiquid | ≥ 0.80 / < 0.80 (коэффициент) |

### 5.2. Алгоритм кластеризации

- **Метод:** Иерархическая агломеративная кластеризация (Average Linkage)
- **Оптимизация K:** Silhouette Score + Davies-Bouldin Index
- **Диапазон K:** 2–15 кластеров
- **Маппинг:** Группы A, B, C приводятся к кластерам группы D

### 5.3. Частота обновления

| Компонент | Частота | Триггер |
| :--- | :--- | :--- |
| **Кластеры** | Ежеквартально | 63 дня или force_recluster |
| **Параметры риска** | Ежедневно | Смена режима рынка |
| **Режим рынка** | Ежедневно | Новые данные IMOEX/VIX |

### 5.4. Кризисный режим (Freeze)

**Триггеры активации (любой из трёх):**
| Триггер | Порог | Источник |
| :--- | :--- | :--- |
| VIX-RUS | > 40 | `crisis.vix_threshold` |
| Просадка IMOEX | < -20% | `crisis.imoex_drawdown` |
| Средняя корреляция | > 0.90 | `crisis.correlation_spike` |

**Действия при активации:**
1. Кластеризация замораживается на **63 дня**
2. Используются последние сохранённые кластеры
3. Параметры риска обновляются ежедневно (по режиму)
4. Все сигналы кризиса логируются для аудита

### 5.5. Устойчивость (Stability)

Для оценки стабильности кластеризации используется **Adjusted Rand Index (ARI)**:

| ARI | Интерпретация | Действие |
| :--- | :--- | :--- |
| **≥ 0.7** | Высокая устойчивость | Норма |
| **0.5 – 0.7** | Умеренная устойчивость | Мониторинг |
| **< 0.5** | Низкая устойчивость | Алерт, анализ |

## 6. Генерация траекторий (Монте-Карло)

### 6.1. Модель доходности акции

Для каждой акции i в режиме r:

$$ r_{i,t} = \alpha_i + \beta_{i,r} \times r_{m,t} + \varepsilon_{i,t} $$

**Где:**
| Параметр | Описание |
| :--- | :--- |
| **r_i,t** | Доходность акции i в день t |
| **α_i** | Альфа акции (дрейф, режим-зависимый) |
| **β_i,r** | Бета для режима r |
| **r_m,t** | Доходность рыночного фактора (IMOEX) |
| **ε_i,t** | Идиосинкратический шум ~ N(0, σ²_idio) |

### 6.2. Алгоритм симуляции с режимами

```
Для каждого дня t = 1 до T:
    1. Проверить переключение режима (цепь Маркова)
    2. Выбрать параметры текущего режима:
       - μ_t = drift[текущий_режим]
       - σ_t = volatility[текущий_режим] × vol_overlay_multiplier
       - Corr_t = base_correlation + correlation_adjustment[режим]
    3. Сгенерировать коррелированные шоки (разложение Холецкого)
    4. Рассчитать доходности: R_t = μ_t + σ_t × Z_corr
    5. Обновить цены: S_t = S_{t-1} × exp(R_t)
```

### 6.3. Количество траекторий

| Сценарий | Количество путей | Использование |
| :--- | :--- | :--- |
| **Базовый** | 10 000 | Ежедневный прогноз, VaR, PFE |
| **Стресс-тесты** | 50 000+ | Кризисные сценарии, регуляторные отчёты |

## 7. Расчёт параметров риска

### 7.1. Базовая формула

Для каждого актива i в режиме r:

$$ \sigma_{adjusted, i, r} = \sigma_{base, i} \times M_{history, i} \times M_{regime, r} \times M_{liquidity, i} $$

$$ \beta_{adjusted, i} = \beta_{base, i} \times M_{history, i} $$

### 7.2. Множители

**История (Conservative):**
| Группа | Beta Mult | Sigma Mult |
| :--- | :--- | :--- |
| A (0–30 дней) | 1.30 | 1.20 |
| B (30–100 дней) | 1.20 | 1.10 |
| C (100–200 дней) | 1.05 | 1.05 |
| D (200+ дней) | 1.00 | 1.00 |

**Режим (пример BEAR_HIGH):**
- Sigma Multiplier: 1.50
- Haircut Multiplier: 1.50
- Correlation Adjustment: +0.25

**Ликвидность:**
| Liquidity Ratio | Multiplier |
| :--- | :--- |
| ≥ 0.80 | 1.0 |
| 0.60 – 0.80 | 1.2 |
| 0.40 – 0.60 | 1.5 |
| < 0.40 | 2.0 |

## 9. Стресс-тестирование

### 9.1. Ограничение роста (Capping)

$$ \max(\text{Цена}_t / \text{Цена}_{t-252}) \leq 10 \text{ для любого } t $$

Траектории, нарушающие правило, каппируются или отбрасываются.

### 9.2. Jump-процесс (Катастрофы)

**Частота событий:**
$$ N \sim \text{Poisson}(\lambda \times T) $$
Где λ = 0.05 (1 событие за 20 лет)

**Величина падения:**
$$ \text{Jump} \sim \text{LogNormal}(\mu, \sigma), \text{ где } E[\text{Jump}] = -40\% $$

**Влияние на корреляции:**
$$ \rho_{ij, shock} = 0.99 \text{ для всех } i, j \text{ на период 5–10 дней после шока} $$

### 9.3. Пресеты стресс-сценариев

| Сценарий | Параметр | Длительность |
| :--- | :--- | :--- |
| Падение рынка | −30% за 21 день | 1 месяц |
| Рост волатильности | σ × 3.0 | 60 дней |
| Замораживание ликвидности | 0 торгов | 30–90 дней |
| Кризисный режим | Freeze кластеров | 63 дня |

## 10. Метрики риска

### 10.1. Value at Risk (VaR)

$$ \text{VaR}_\alpha = -q_\alpha $$

Где $q_\alpha$ — α-квантиль распределения доходностей (обычно α = 1% или 5%)

### 10.2. Expected Shortfall (ES)

$$ \text{ES}_\alpha = E[L \mid L > \text{VaR}_\alpha] $$

Условное математическое ожидание потерь при превышении VaR.

### 10.3. Potential Future Exposure (PFE)

$$ \text{PFE}(T, \lambda) = q_\lambda(V_1(T), V_2(T), ..., V_N(T)) $$

**Где:**
| Параметр | Описание | Значение |
| :--- | :--- | :--- |
| **T** | Горизонт расчёта | 252 дня (1 год) |
| **λ** | Доверительный уровень | 95% |
| **N** | Количество сценариев | 10 000 путей |
| **Vᵢ(T)** | Стоимость портфеля в пути i | Из симуляции |

**Результат:**
- Без режимов: PFE = 1.35 × начальная стоимость
- С режимами: PFE = 1.52 × начальная стоимость (**+13%**)

### 10.4. Exposure at Default (EAD)

$$ \text{EAD}(T) = \alpha \times \max(\text{EPE}(T)), \text{ где } \alpha = 1.4 $$

### 10.5. Тесты качества VaR

**Тест Купиека (безусловное покрытие):**
$$ LR_{uc} = -2 \times \ln\left((1-\alpha)^{N-x} \times \alpha^x\right) + 2 \times \ln\left((1-\frac{x}{N})^{N-x} \times (\frac{x}{N})^x\right) $$

**Тест Кристофферсена (независимость промахов):**
$$ LR_{ind} = -2 \times \ln\left(\frac{L(\Pi_0)}{L(\Pi_1)}\right) $$

**Критерий:** p-value > 0.05 для обоих тестов

## 12. Ограничения модели

| Ограничение | Описание | Влияние | Митигация |
| :--- | :--- | :--- | :--- |
| **Нормальность доходностей** | Не учитывает тяжёлые хвосты | Недооценка экстремальных рисков | Jump-процесс, t-распределение |
| **Стационарность параметров** | β и корреляции постоянны внутри режима | Ошибки при структурных сдвигах | Ежедневное обновление, консервативные множители |
| **Историческая калибровка** | Параметры основаны на прошлом | Нет гарантии повторения в будущем | Walk-Forward, стресс-сценарии |
| **Ликвидность** | Упрощённая модель ликвидности | Риск при замораживании рынка | Liquidity Premium, Haircuts |
| **Внешние шоки** | Jump-процесс упрощён | Нет моделирования специфических событий | Пресеты стресс-сценариев |
| **Лаг макро-данных** | Макро-индикаторы с задержкой | Устаревшие сигналы | Fallback на последнее значение |

## 14. Соответствие PFE Methodology

| Раздел | Требование | Реализация | Статус |
| :--- | :--- | :--- | :--- |
| **1.1 PFE(T, λ)** | `PFE(T, λ) = q_λ(e₁(T), ..., eₙ(T))` | Квантиль из 10 000 путей Монте-Карло | Полное |
| **1.2 EAD** | `EAD(T) = α × max EPE(T)`, α = 1.4 | Применяется к максимальному exposure | Полное |
| **1.2.1 EPE** | `EPE(T) = (1/N) × Σ eᵢ(T)` | Среднее по всем симуляциям | Полное |
| **3.4.1 MR(T)*** | `MR = Σ Sₗ × MRRₗ × \|Q\|` | Haircuts зависят от Vol Overlay | Полное |
| **3.4.2 PR(T)*** | Процентный риск | High Vol → консервативные ставки | Полное |
