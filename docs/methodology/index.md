# Методология Equity Model

**Версия:** 0.1.0  
**Дата:** 2026-02-23  
**Статус:** В разработке

---

## 1. Обзор модели

**Equity Model** — это иерархическая модель Монте-Карло для прогнозирования цен акций с учётом рыночных режимов (Бык/Медведь), стресс-сценариев и инфляции.

### 1.1. Назначение

- Краткосрочное прогнозирование (до 90 дней)
- Долгосрочное прогнозирование (до 40 лет)
- Оценка рыночных рисков (VaR, Expected Shortfall)
- Стресс-тестирование портфеля

### 1.2. Область применения

- Инструменты: 260+ акций российского рынка
- Горизонты: 1 день — 40 лет
- Частота обновления: ежедневно (прогноз), ежеквартально (калибровка)

## 2. Ключевые допущения

| Допущение | Описание | Риск при нарушении | Митигация |
| :--- | :--- | :--- | :--- |
| **Нормальность доходностей** | Внутри режима доходности ~ N(μ, σ²) | Недооценка хвостовых рисков | Возможность замены на t-распределение |
| **Стационарность β** | β не меняется внутри режима | Ошибки в кризисных периодах | Тест Чоу, скользящее окно |
| **Постоянство матрицы переходов** | P не меняется со временем | Структурные сдвиги в экономике | Проверка по десятилетиям, MS-AR |
| **Иерархическая структура** | 3 уровня корреляций | Упрощение зависимостей | Валидация на исторических данных |
| **Обработка пропусков** | Forward fill для цен, исключение при >20% | Искажение ликвидности | Фильтрация по ликвидности |

## 3. Структура модели

### 3.1. Иерархия корреляций

```
Уровень 1: Рыночные корреляции (между кластерами)
    ↓
Уровень 2: Внутрикластерные корреляции
    ↓
Уровень 3: Индивидуальные параметры акций (β, σ_idio)
```

### 3.2. Формула сборки корреляции

Для акций i и j:

```
Если i, j в одном кластере k:
    ρ_ij = ρ_cluster(k) × β_i × β_j

Если i, j в разных кластерах:
    ρ_ij = ρ_market × β_i × β_j
```

Где:
- ρ_market — рыночная корреляция (режим-зависимая)
- ρ_cluster(k) — внутрикластерная корреляция для кластера k
- β_i, β_j — бета-коэффициенты акций

## 4. Идентификация рыночных режимов

### 4.1. Правило переключения

```
Режим_t = Bull, если Price_t > SMA(окно)_t
Режим_t = Bear, если Price_t ≤ SMA(окно)_t
```

**Параметры:**
- Окно SMA: оптимизируется (диапазон 150-250 дней)
- Применение: индивидуально для каждой акции

### 4.2. Матрица переходов Маркова

Для долгосрочной модели режимы переключаются по цепи Маркова:

```
P = | P(Bull→Bull)    P(Bull→Bear)  |
    | P(Bear→Bull)   P(Bear→Bear)  |
```

**Условие нормализации:**
```
P(Bull→Bull) + P(Bull→Bear) = 1
P(Bear→Bull) + P(Bear→Bear) = 1
```

### 4.3. Стационарное распределение

```
π × P = π
```

Где π = (π_bull, π_bear) — стационарное распределение режимов.

## 5. Генерация траекторий (Монте-Карло)

### 5.1. Модель доходности акции

Для каждой акции i в режиме r ∈ {Bull, Bear}:

```
r_i,t = α_i + β_i,r × r_m,t + ε_i,t
```

Где:
- r_i,t — доходность акции i в день t
- α_i — альфа акции (дрейф)
- β_i,r — бета для режима r
- r_m,t — доходность рыночного фактора
- ε_i,t — идиосинкратический шум ~ N(0, σ²_idio)

### 5.2. Генерация многомерных случайных величин

Используется разложение Холецкого для учёта корреляций:

```
Z = L × X
```

Где:
- X — вектор независимых стандартных нормальных величин
- L — нижняя треугольная матрица (разложение Холецкого корреляционной матрицы)
- Z — вектор коррелированных нормальных величин

### 5.3. Количество траекторий

- Базовое: N = 10,000
- Для стресс-тестов: N = 50,000+

## 6. Краткосрочная vs Долгосрочная модель

### 6.1. Краткосрочная модель (< 90 дней)

| Параметр | Значение |
| :--- | :--- |
| Горизонт | 1-90 дней |
| Переключение режимов | Динамическое (по SMA) |
| Окно SMA | Оптимизируется (150-250 дней) |
| Валидация | Walk-Forward, тесты VaR |

### 6.2. Долгосрочная модель (до 40 лет)

| Параметр | Значение |
| :--- | :--- |
| Горизонт | 1-40 лет |
| Переключение режимов | Марковская цепь |
| Инфляция | 4% годовых (база) |
| Валидация | Стационарность, историческое сравнение |

### 6.3. Точка переключения

Гибридная модель использует:
- Краткосрочную модель для горизонтов ≤ H дней
- Долгосрочную модель для горизонтов > H дней

**Оптимальный порог H:** определяется на Этапе 7 (около 60 дней)

## 7. Стресс-тестирование

### 7.1. Ограничение роста (Capping)

```
max(Цена_t / Цена_t-252) ≤ 10 для любого t
```

Траектории, нарушающие правило, каппируются или отбрасываются.

### 7.2. Jump-процесс (Катастрофы)

**Частота событий:**
```
N ~ Poisson(λ × T)
```
Где λ = 0.05 (1 событие за 20 лет)

**Величина падения:**
```
Jump ~ LogNormal(μ, σ), где E[Jump] = −40%
```

**Влияние на корреляции:**
```
ρ_ij, shock = 0.99 для всех i, j на период 5-10 дней после шока
```

### 7.3. Пресеты стресс-сценариев

| Сценарий | Параметр | Длительность |
| :--- | :--- | :--- |
| Падение рынка | −30% за 21 день | 1 месяц |
| Рост волатильности | σ × 3.0 | 60 дней |
| Замораживание ликвидности | 0 торгов | 30-90 дней |

## 8. Метрики риска

### 8.1. Value at Risk (VaR)

```
VaR_α = −q_α
```

Где q_α — α-квантиль распределения доходностей (обычно α = 1% или 5%)

### 8.2. Expected Shortfall (ES)

```
ES_α = E[L | L > VaR_α]
```

Условное математическое ожидание потерь при превышении VaR.

### 8.3. Тесты качества VaR

**Тест Купиека (безусловное покрытие):**
```
LR = −2 × ln((1−α)^(N−x) × α^x) + 2 × ln((1−x/N)^(N−x) × (x/N)^x)
```
Распределение: LR ~ χ²(1)  
Критерий: p-value > 0.05

**Тест Кристофферсена (независимость промахов):**
```
LR_ind = −2 × ln(L(Π_0) / L(Π_1))
```
Распределение: LR_ind ~ χ²(1)  
Критерий: p-value > 0.05

## 10. Ограничения модели

| Ограничение | Описание | Влияние |
| :--- | :--- | :--- |
| **Нормальность доходностей** | Не учитывает тяжёлые хвосты | Недооценка экстремальных рисков |
| **Стационарность параметров** | β и корреляции постоянны внутри режима | Ошибки при структурных сдвигах |
| **Историческая калибровка** | Параметры основаны на прошлом | Нет гарантии повторения в будущем |
| **Ликвидность** | Упрощённая модель ликвидности | Риск при замораживании рынка |
| **Внешние шоки** | Jump-процесс упрощён | Нет моделирования специфических событий |
