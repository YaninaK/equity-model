# Equity Model Documentation

Система прогнозирования цен акций на основе иерархической модели Монте-Карло. Поддерживает краткосрочное (до 90 дней) и долгосрочное (до 40 лет) моделирование с учётом рыночных режимов, стресс-сценариев и инфляции.
