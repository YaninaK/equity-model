### 3. Технические спецификации и логика

#### 3.1. Расчет взвешенной корреляции

Используется экспоненциальное взвешивание для учета важности свежих данных:

```
Cov_t(X, Y) = (1 − λ) × Σ(i=0 to N) λ^i × (X_t−i − X̄)(Y_t−i − Ȳ)
```

Где:
- λ = 0.94 — коэффициент затухания
- N — размер окна наблюдения (например, 504 торговых дня)
- X̄, Ȳ — взвешенные средние значения доходностей

Корреляция вычисляется на основе взвешенных ковариаций и дисперсий.


#### 3.2. Метрика расстояния

Для иерархической кластеризации корреляция преобразуется в расстояние:

```
D_ij = sqrt(2 × (1 - ρ_ij))
```

Где ρ_ij — коэффициент корреляции между инструментами i и j. Это гарантирует выполнение неравенства треугольника и корректную работу метрики Ward.


#### 3.3. Оценка устойчивости (ARI)

Adjusted Rand Index сравнивает два разбиения (например, кластеризация в марте vs кластеризация в июне):

- ARI = 1 — Полное совпадение разбиений
- ARI = 0 — Случайное совпадение

Порог устойчивости:
- Если ARI_t,t-1 < 0.7 более чем для 2 соседних периодов подряд, считается, что структура рынка нестабильна для выбранного k


#### 3.4. Логика выбора числа кластеров

Выбор k осуществляется по совокупности факторов:

- **Silhouette Score:** Должен быть локальным максимумом
- **Интерпретируемость:** Кластеры должны примерно соответствовать отраслям (например, Нефть, Банки, IT), что проверяется через метаданные из Этапа 1
- **Устойчивость:** При выбранном k должен выполняться критерий ARI > 0.7

### 3. Технические спецификации и логика

#### 3.1. Идентификация режимов

Порог SMA(200):

```
Режим_t = Bull, если Price_t > SMA(200)_t
Режим_t = Bear, если Price_t <= SMA(200)_t
```

Требование к данным: Минимум 200 торговых дней истории для расчета первого значения SMA.


#### 3.2. Модель DCC-GARCH(1,1)

Уравнение динамической корреляции:

```
Q_t = (1 − α − β) × Q̄ + α × ε_t−1 × ε_t−1′ + β × Q_t−1
R_t = diag(Q_t)^(-1/2) × Q_t × diag(Q_t)^(-1/2)
```

Где:
- Q_t — матрица условных ковариаций стандартизированных остатков
- R_t — матрица условных корреляций (целевая)
- α — реакция на новые шоки (обычно 0.01-0.05)
- β — персистентность корреляций (обычно 0.90-0.98)
- α + β < 1 — условие стационарности

Ограничение: α + β должно быть строго меньше 1 для стационарности процесса.


#### 3.3. Регрессия для калибровки бет

Модель для каждой акции:

```
r_i,t = α_i + β_i × r_m,t + ε_i,t
```

Параметры для сохранения:
- beta_bull — бета в бычьем режиме
- beta_bear — бета в медвежьем режиме
- sigma_idio — стандартное отклонение остатков ε (идиосинкратический риск)



#### 3.4. Тест Чоу на структурные сдвиги

Гипотезы:
- H_0: Параметры регрессии постоянны во времени (нет структурного сдвига)
- H_1: Параметры изменяются в точке сдвига (требуется раздельная оценка)

Критерий: Если p-value < 0.05, отвергаем H_0 и используем скользящее окно для оценки бет.


#### 3.5. Иерархическая структура корреляций

| Уровень | Описание | Параметры |
| :--- | :--- | :--- |
| Уровень 1 | Корреляция между кластерами | rho_market_bull, rho_market_bear |
| Уровень 2 | Корреляция внутри кластера | rho_cluster_k_bull, rho_cluster_k_bear |
| Уровень 3 | Индивидуальные параметры акции | beta_bull, beta_bear, sigma_idio |

Формула сборки корреляции между акциями i и j:

```
ρ_ij = ρ_cluster(k) × β_i × β_j, если i, j в одном кластере
ρ_ij = ρ_market × β_i × β_j, если i, j в разных кластерах
```
