### 3. Технические спецификации и логика

#### 3.1. Расчет взвешенной корреляции

Используется экспоненциальное взвешивание для учета важности свежих данных:

```
Cov_t(X, Y) = (1 − λ) × Σ(i=0 to N) λ^i × (X_t−i − X̄)(Y_t−i − Ȳ)
```

Где:
- λ = 0.94 — коэффициент затухания
- N — размер окна наблюдения (например, 504 торговых дня)
- X̄, Ȳ — взвешенные средние значения доходностей

Корреляция вычисляется на основе взвешенных ковариаций и дисперсий.


#### 3.2. Метрика расстояния

Для иерархической кластеризации корреляция преобразуется в расстояние:

```
D_ij = sqrt(2 × (1 - ρ_ij))
```

Где ρ_ij — коэффициент корреляции между инструментами i и j. Это гарантирует выполнение неравенства треугольника и корректную работу метрики Ward.


#### 3.3. Оценка устойчивости (ARI)

Adjusted Rand Index сравнивает два разбиения (например, кластеризация в марте vs кластеризация в июне):

- ARI = 1 — Полное совпадение разбиений
- ARI = 0 — Случайное совпадение

Порог устойчивости:
- Если ARI_t,t-1 < 0.7 более чем для 2 соседних периодов подряд, считается, что структура рынка нестабильна для выбранного k


#### 3.4. Логика выбора числа кластеров

Выбор k осуществляется по совокупности факторов:

- **Silhouette Score:** Должен быть локальным максимумом
- **Интерпретируемость:** Кластеры должны примерно соответствовать отраслям (например, Нефть, Банки, IT), что проверяется через метаданные из Этапа 1
- **Устойчивость:** При выбранном k должен выполняться критерий ARI > 0.7

### 3. Технические спецификации и логика

#### 3.1. Идентификация режимов

Порог SMA(200):

```
Режим_t = Bull, если Price_t > SMA(200)_t
Режим_t = Bear, если Price_t <= SMA(200)_t
```

Требование к данным: Минимум 200 торговых дней истории для расчета первого значения SMA.


#### 3.2. Модель DCC-GARCH(1,1)

Уравнение динамической корреляции:

```
Q_t = (1 − α − β) × Q̄ + α × ε_t−1 × ε_t−1′ + β × Q_t−1
R_t = diag(Q_t)^(-1/2) × Q_t × diag(Q_t)^(-1/2)
```

Где:
- Q_t — матрица условных ковариаций стандартизированных остатков
- R_t — матрица условных корреляций (целевая)
- α — реакция на новые шоки (обычно 0.01-0.05)
- β — персистентность корреляций (обычно 0.90-0.98)
- α + β < 1 — условие стационарности

Ограничение: α + β должно быть строго меньше 1 для стационарности процесса.


#### 3.3. Регрессия для калибровки бет

Модель для каждой акции:

```
r_i,t = α_i + β_i × r_m,t + ε_i,t
```

Параметры для сохранения:
- beta_bull — бета в бычьем режиме
- beta_bear — бета в медвежьем режиме
- sigma_idio — стандартное отклонение остатков ε (идиосинкратический риск)



#### 3.4. Тест Чоу на структурные сдвиги

Гипотезы:
- H_0: Параметры регрессии постоянны во времени (нет структурного сдвига)
- H_1: Параметры изменяются в точке сдвига (требуется раздельная оценка)

Критерий: Если p-value < 0.05, отвергаем H_0 и используем скользящее окно для оценки бет.


#### 3.5. Иерархическая структура корреляций

| Уровень | Описание | Параметры |
| :--- | :--- | :--- |
| Уровень 1 | Корреляция между кластерами | rho_market_bull, rho_market_bear |
| Уровень 2 | Корреляция внутри кластера | rho_cluster_k_bull, rho_cluster_k_bear |
| Уровень 3 | Индивидуальные параметры акции | beta_bull, beta_bear, sigma_idio |

Формула сборки корреляции между акциями i и j:

```
ρ_ij = ρ_cluster(k) × β_i × β_j, если i, j в одном кластере
ρ_ij = ρ_market × β_i × β_j, если i, j в разных кластерах
```

### 3. Технические спецификации и логика

#### 3.1. Правило переключения режимов

```
Режим_t+1 = Bear, если Price_t <= SMA(окно)_t
Режим_t+1 = Bull, если Price_t > SMA(окно)_t
```

Режим определяется по цене закрытия дня t и применяется для прогноза на день t+1 (без утечки данных).


#### 3.2. Генерация траекторий (Монте-Карло)

Для каждой траектории m = 1...M:

```
r_i,t^(m) = α_i + β_i,regime × r_m,t^(m) + ε_i,t^(m)
```

Где:
- r_m,t^(m) — симулированная доходность рынка (из GARCH или исторического распределения)
- β_i,regime — бета для текущего режима (bull или bear)
- ε_i,t^(m) — идиосинкратический шум с учётом внутрикластерных корреляций


#### 3.3. Метрики качества прогноза

**Coverage Rate (CR):**

```
CR = (1 / N) × Σ I(q_5% <= факт <= q_95%)
```

Где:
- q_5%, q_95% — 5-й и 95-й процентили симулированного распределения
- I() — индикаторная функция (1 если условие истинно, 0 иначе)

Цель: CR ≈ 0.90 (для 90% доверительного интервала)

---

**Winkler Score (WS):**

```
WS = (q_95 − q_5), если q_5 <= факт <= q_95
WS = (q_95 − q_5) + 2 × (q_5 − факт), если факт < q_5
WS = (q_95 − q_5) + 2 × (факт − q_95), если факт > q_95
```

Цель: Минимизация среднего WS по всем итерациям.

---

**Probability Integral Transform (PIT):**

```
PIT_t = F_t(факт_t)
```

Где F_t() — кумулятивная функция распределения прогноза на день t.

Тест Колмогорова-Смирнова: Проверка, что PIT ~ Uniform(0, 1). p-value > 0.05 указывает на корректность распределения.


#### 3.4. Критерий выбора окна SMA

```
Оптимальное окно = argmin(Winkler) при условии CR > 0.85
```

Дополнительные требования:
- Тест КС для PIT: p-value > 0.05
- Частота переключений режимов: не более 10-15 раз в год (избегание «пилы»)
- Устойчивость: метрики не должны деградировать более чем на 20% в кризисные периоды

### 3. Технические спецификации и логика

#### 3.1. Матрица переходов Маркова

Матрица переходов P:

```
| P(Bull→Bull)    P(Bull→Bear) |
| P(Bear→Bull)   P(Bear→Bear) |
```

Условие нормализации:

```
P(Bull→Bull) + P(Bull→Bear) = 1
P(Bear→Bull) + P(Bear→Bear) = 1
```


#### 3.2. Стационарное распределение

```
π × P = π
```

Где:
- π = (π_bull, π_bear) — стационарное распределение
- π_bull + π_bear = 1

Вычисление: Собственный вектор матрицы P, соответствующий собственному значению λ = 1.

Критерий согласия:

```
|π_исторический − π_стационарный| < 0.05
```


#### 3.3. Генерация последовательности режимов

Для каждого шага t = 1...T:

```
Режим_t = Sample(P[Режим_t−1, :])
```

Где Sample() — случайная выборка согласно вероятностям перехода.


#### 3.4. Инфляционная корректировка

```
Номинальные цены = Реальные цены × (1 + инфляция)^(t / 365)
```

Где:
- t — номер торгового дня с начала симуляции
- инфляция — годовая ставка (базово 0.04 = 4%)
- 365 — количество торговых дней в году

Критерий успеха:

```
При инфляции 4% за 40 лет: (1.04)^40 ≈ 4.8
```

#### 3.5. Иерархическая генерация доходностей

В каждом режиме (Bull/Bear):

```
r_i,t = α_i + β_i,regime × r_m,t + ε_i,t
```

Где параметры β и корреляции берутся из Этапа 3 для соответствующего режима.

### 3. Технические спецификации и логика

#### 3.1. Ограничение роста (Capping)

**Правило:**

```
max(Цена_t / Цена_t−252) ≤ 10 для любого t
```

**Алгоритм:**

```
Если Цена_t > 10 × Цена_t−252:
    Цена_t = 10 × Цена_t−252
```


#### 3.2. Моделирование катастроф (Jump Process)

**Частота событий:**

```
N ~ Poisson(λ × T)
```

Где:
- λ = 0.05 — интенсивность (1 событие за 20 лет)
- T — горизонт симуляции в годах

**Величина падения:**

```
Jump ~ LogNormal(μ, σ), где E[Jump] = −40%
```

Диапазон: 30-50% падения от текущей цены.

**Влияние на корреляции:**

```
ρ_ij, shock = 0.99 для всех i, j на период 5-10 дней после шока
```


#### 3.3. Стресс-сценарии

| Сценарий | Параметр | Длительность |
| :--- | :--- | :--- |
| Падение рынка | −30% за 21 день | 1 месяц |
| Рост волатильности | σ × 3.0 | 60 дней |
| Замораживание ликвидности | 0 торгов | 30-90 дней |

**Формула применения шока:**

```
r_i,t, stress = r_i,t, base × ShockFactor
```

Где ShockFactor зависит от выбранного сценария.


#### 3.4. Последовательность применения

1. Генерация базовых траекторий (Этапы 4-5)
2. Применение катастроф (Jump Process)

### 3. Технические спецификации и логика

#### 3.1. Метрики сравнения

**RMSE медианного прогноза:**

```
RMSE = sqrt(1/N × Σ (Медиана_прогноза_t − Факт_t)²)
```

**Coverage Rate (5-95%):**

```
CR = (1/N) × Σ I(q_5% ≤ Факт_t ≤ q_95%)
```

**Winkler Score:**

```
WS = (q_95 − q_5) + 2 × max(0, q_5 − Факт) + 2 × max(0, Факт − q_95)
```

Где:
- N — количество тестовых дат (10) × количество инструментов
- q_5%, q_95% — 5-й и 95-й процентили симулированного распределения


#### 3.2. Критерий выбора модели на горизонте

```
Модель_лучшая(h) = argmin(RMSE, Winkler) при CR > 0.85
```

Где h — горизонт прогноза в днях.


#### 3.3. Определение порогового горизонта H

```
H = min{h : Долгосрочная_модель(h) лучше Краткосрочной_модель(h)}
```

Дополнительные требования:
- Разница в метриках статистически значима (p-value < 0.05)
- Преимущество долгосрочной модели сохраняется на всех горизонтах > H
- Устойчивость к изменению тестовых дат (проверка на 5 разных наборах по 10 дат)


#### 3.4. Адаптивный порог (опционально)

```
H(volatility) = H_base × (1 + k × (σ_текущая − σ_средняя))
```

Где:
- H_base — базовый порог (например, 60 дней)
- σ_текущая — текущая волатильность рынка
- σ_средняя — историческая средняя волатильность
- k — коэффициент чувствительности (калибруется на истории)


#### 3.5. Гибридная модель

```
Прогноз(t) = Краткосрочная_модель(t), если t ≤ H
Прогноз(t) = Долгосрочная_модель(t), если t > H
```

Требование непрерывности:

```
Медиана_краткосрочная(H) ≈ Медиана_долгосрочная(H)
```

Допустимое расхождение: < 5%

### 3. Технические спецификации и логика

#### 3.1. Процедура Walk-Forward

| Параметр | Значение |
| :--- | :--- |
| Начальная дата | T-335 дней (после offset 30 дней) |
| Шаг | 30 дней |
| Количество итераций | Около 8 |
| Горизонт прогноза | 30, 60, 90 дней (не 365) |

На каждой итерации i:
- Калибровка на данных [T_start, T_i]
- Прогноз на [T_i+1, T_i+H] где H ∈ {30, 60, 90}
- Сохранение квантилей и фактов для доступного горизонта
- Сдвиг на 30 дней вперёд

Прогноз на 365 дней строится только для долгосрочной модели (Этап 5), но валидация VaR проводится только на горизонтах 30, 60, 90 дней в рамках доступных 335 дней.


#### 3.2. Тест Купиека (Kupiec Test)

**Проверяет:** Соответствует ли частота промахов заявленному уровню риска?

**Статистика LR:**

```
LR = −2 × ln((1−α)^(N−x) × α^x) + 2 × ln((1−x/N)^(N−x) × (x/N)^x)
```

Где:
- α — уровень квантиля (например, 0.01 для 1%)
- N — общее количество наблюдений
- x — количество промахов (факт < квантиль)

**Распределение:** LR ~ χ²(1) (хи-квадрат с 1 степенью свободы)

**Критерий:** p-value > 0.05


#### 3.3. Тест Кристофферсена (Christoffersen Test)

**Проверяет:** Независимы ли промахи во времени (нет ли кластеризации)?

**Гипотезы:**
- H_0: Промахи независимы (случайны)
- H_1: Промахи кластеризуются (после промаха чаще бывает промах)

**Статистика LR:**

```
LR_ind = −2 × ln(L(Π_0) / L(Π_1))
```

Где:
- L(Π_0) — правдоподобие при условии независимости
- L(Π_1) — правдоподобие при условии зависимости (Марковская цепь 1-го порядка)

**Распределение:** LR_ind ~ χ²(1)

**Критерий:** p-value > 0.05 (промахи не кластеризуются)


#### 3.4. Анализ корреляционного кризиса

**Определение стресс-периода:**

```
Падение индекса > 5% за 21 торговый день
```

**Ожидаемое поведение модели:**

```
ρ_стресс ≈ 0.95 (корреляции стремятся к 1)
ρ_спокойный ≈ 0.70 (бычий режим)
```

**Метрика качества:**

```
Доля стресс-периодов, где ρ_симуляция > 0.90
```

**Цель:** > 80%

### 3. Технические спецификации и логика

#### 3.1. Паспорт методологии — ключевые допущения

| Допущение | Описание | Риск при нарушении |
| :--- | :--- | :--- |
| Нормальность доходностей | Внутри режима доходности ~ N(μ, σ²) | Недооценка хвостовых рисков |
| Стационарность бет | β не меняется внутри режима | Ошибки в кризисных периодах |
| Постоянство матрицы переходов | P не меняется со временем | Структурные сдвиги в экономике |
| Обработка пропусков | Forward fill для цен, исключение при >20% | Искажение ликвидности |

**Митигация:** Возможность замены нормального распределения на t-распределение с тяжёлыми хвостами.


#### 3.2. Структура дашборда

**Раздел 1: Обзор рынка**
- Траектории симуляций IMOEX (10,000 путей)
- Доверительные интервалы (5%, 50%, 95%)

**Раздел 2: Топ-10 акций**
- Фан-чарты для каждой акции
- Распределение конечных цен

**Раздел 3: Долгосрочный прогноз**
- Распределение цен через 40 лет
- Влияние инфляции (реальные vs номинальные)

**Раздел 4: Риски**
- VaR, ES по портфелю
- Результаты тестов Купиека/Кристофферсена


#### 3.3. Расписание отчётности

| Отчёт | Частота | Получатели | Содержание |
| :--- | :--- | :--- | :--- |
| Ежедневный | Каждый торговый день | Риск-менеджеры | VaR, ES, стресс-потери |
| Еженедельный | Каждый понедельник | Заинтересованные стейкхолдеры | Изменения в симуляциях, алёрты |
| Ежеквартальный | Раз в квартал | Комитет по рискам | Качество модели, бэктестинг |
| Годовой | Раз в год | Аудиторы, руководство | Полный пересмотр методологии |

- Все документы версионированы и хранятся в корпоративном репозитории
- Обучение стейкхолдеров проведено (минимум 1 сессия)
