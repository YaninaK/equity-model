# Дорожная карта проекта Equity Model

> **Симуляция Монте-Карло с режимами "Бык/Медведь" для оценки стоимости акций (горизонт до 40 лет)**

---

## Обзор проекта

| Параметр | Значение |
| :--- | :--- |
| **Инструменты** | 260+ акций |
| **Горизонт прогноза** | 1 день — 40 лет |
| **Режимы рынка** | Bull / Bear (SMA-based) |
| **Методология** | Иерархическая модель Монте-Карло |
| **Статус** | В разработке (v0.1.0-dev) |

---

## 10 Этапов реализации

### **Этап 1** — Инфраструктура данных
| | |
| :--- | :--- |
| **Статус** | В работе |
| **Результат** | Витрина данных для 260+ инструментов |

**Цель:** Обеспечить чистый, непротиворечивый пайплайн данных для 260+ инструментов с учётом ликвидности и пропусков.

**Ключевые задачи:**
- Ежедневные цены закрытия (Total Return Index или с корректировкой на дивиденды)
- Фильтрация по ликвидности: исключение бумаг с >20% пропусков за 2 года
- Заполнение пропусков: forward fill для цен, удаление дней без торгов по рынку
- Минимальная история для калибровки: ≥2 лет непрерывных данных
- Разделение выборки: обучение (до T-365), тест (последние 365 дней), валидация (Walk-Forward 335 дней)

**Deliverables:**
- Модуль `equity_model.data` (loader, cleaner, validator)
- Витрина данных (Parquet): цены, логарифмические доходности, флаги пропусков, метаданные

[Подробнее](DEVELOPMENT_PLAN.md#этап-1-инфраструктура-данных-и-подготовкa)

### **Этап 2** — Кластеризация активов
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | ~7 стабильных кластеров (ARI > 0.7) |

**Цель:** Сгруппировать 260+ акций в оптимальное число кластеров для снижения размерности с проверкой устойчивости.

**Ключевые задачи:**
- Расчёт исторических корреляций: скользящее окно 2 года, exponential weighting
- Выбор числа кластеров: Hierarchical / K-Means, k = 2…15
- Метрики качества: силуэтный коэффициент, inertia, индекс Дэвиса-Болдина
- Проверка устойчивости: ARI > 0.7 между соседними квартальными разбиениями
- При нестабильности: уменьшение числа кластеров или fuzzy clustering

**Deliverables:**
- Модуль `equity_model.clustering`
- Файл соответствия тикеров и кластеров (CSV)
- Отчёт по выбору гиперпараметров

### **Этап 3** — Калибровка иерархической модели
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Параметры β, ρ, σ для Bull/Bear режимов |

**Цель:** Оценить параметры для всех уровней в зависимости от режима, используя исторические данные для верификации целевых корреляций.

**Ключевые задачи:**
- Идентификация режимов: Bear = цена < SMA(200), Bull = цена > SMA(200)
- Рыночные корреляции (Уровень 1): ρ_market ≈ 0.70 (бык), 0.95 (медведь)
- DCC-GARCH(1,1) для динамических условных корреляций
- Внутрикластерные корреляции (Уровень 2): проверка ρ_cluster в разных режимах
- Калибровка акций (Уровень 3): β_bull, β_bear, σ_idio через регрессию на индекс
- Тест Чоу на структурные сдвиги бет во времени

**Deliverables:**
- Модуль `equity_model.calibration`
- Файл параметров (β, ρ, σ) по режимам и кластерам
- Отчёт по верификации корреляций

[Подробнее](DEVELOPMENT_PLAN.md#этап-3-калибровка-иерархической-модели-с-верификацией-корреляций)

### **Этап 4** — Краткосрочная модель (< 90 дней)
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Оптимальное SMA-окно (CR > 85%) |

**Цель:** Построить максимально точный прогноз на коротком горизонте с динамическим переключением режимов по SMA.

**Ключевые задачи:**
- Симуляция N траекторий (10,000) с динамическим переключением режимов
- Правило переключения: Price < SMA → Bear, Price > SMA → Bull
- Оптимизация окна SMA: диапазон 150–250 дней, шаг 5 дней
- Walk-Forward валидация: 335 дней, шаг 30 дней
- Метрики: Coverage Rate (цель ≈90%), Winkler Score, PIT + тест Колмогорова-Смирнова

**Deliverables:**
- Модуль `equity_model.short_term`
- Файл с оптимальным окном SMA
- Отчёт по метрикам качества прогноза

[Подробнее](DEVELOPMENT_PLAN.md#этап-4-краткосрочная-модель-менее-90-дней-и-оптимизация-sma)

### **Этап 5** — Долгосрочная модель (до 40 лет)
| | |
| :--- | :--- |
| **Статус** | 📋 Запланировано |
| **Результат** | Марковская матрица переходов + инфляция |

**Цель:** Построить симуляции, где режимы сменяются по цепи Маркова с проверкой стационарности и возможностью добавления инфляции.

**Ключевые задачи:**
- Матрица переходов Маркова: P(Bull→Bull), P(Bull→Bear), P(Bear→Bull), P(Bear→Bear)
- Стационарное распределение π = (π_bull, π_bear) как собственный вектор
- Проверка: расхождение с исторической долей режимов <5%
- Модель Markov Switching (MS-AR) при нестационарности переходов
- Симуляция на 40 лет (40×365 дней) с иерархической структурой
- Инфляция: номинальные цены = реальные × (1 + инфляция)^t (база 4%)
- Критерий успеха: (1.04)^40 ≈ 4.8× рост за 40 лет

**Deliverables:**
- Модуль `equity_model.long_term`
- Файл матрицы переходов и стационарного распределения
- Отчёт по долгосрочным симуляциям

[Подробнее](DEVELOPMENT_PLAN.md#этап-5-долгосрочная-модель-до-40-лет-с-марковскими-переходами-и-инфляцией)

### **Этап 6** — Защита от экстремальных сценариев
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Jump-процессы и стресс-пресеты |

**Цель:** Ограничить нереалистичные траектории и обеспечить возможность стресс-тестирования.

**Ключевые задачи:**
- Ограничение роста: максимум 10× за скользящий год (каппирование или отбрасывание)
- Jump-процесс: Пуассон с λ = 0.05 (раз в 20 лет), падение −40% (диапазон 30–50%)
- Синхронная катастрофа: корреляция = 1, временный рост до 0.99
- Стресс-пресеты:
  - Падение рынка на 30% за месяц
  - Рост волатильности в 3 раза
  - Замораживание ликвидности

**Deliverables:**
- Модуль `equity_model.stress`
- Файл параметров стресс-сценариев
- Отчёт по стресс-тестированию

### **Этап 7** — Сравнение моделей
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Порог переключения H (≈60 дней) |

**Цель:** Определить оптимальный горизонт перехода от краткосрочной модели (с SMA) к долгосрочной (Марковской).

**Ключевые задачи:**
- Дизайн эксперимента: 10 случайных дат из тестового периода
- Горизонты сравнения: 30, 45, 60, 75, 90, 120 дней
- Метрики: RMSE медианного прогноза, Coverage Rate (5–95%), Winkler Score
- Выбор порога H: горизонт, где долгосрочная модель стабильно лучше
- Опционально: адаптивный порог H(volatility)

**Deliverables:**
- Модуль `equity_model.comparison`
- Файл с порогом переключения H
- Отчёт по сравнению моделей

[Подробнее](DEVELOPMENT_PLAN.md#этап-7-сравнение-моделей-поиск-точки-переключения)

### **Этап 8** — Финальное бэктестирование
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Тесты VaR (Купиек, Кристофферсен p > 0.05) |

**Цель:** Подтвердить работоспособность модели на неиспользованных данных, включая формальные тесты прогнозов квантилей.

**Ключевые задачи:**
- Walk-Forward: T-365, шаг 30 дней, ≈10 итераций
- Прогноз на 1 год вперёд с переключением по порогу H
- Квантили: 1%, 5%, 95%, 99% для горизонтов 30, 60, 90 дней
- Тест Купиека: безусловное покрытие (LR-тест, p-value > 0.05)
- Тест Кристофферсена: независимость промахов во времени
- Валидация "корреляционного кризиса": ρ → 0.95 при падении индекса >5% за месяц

**Deliverables:**
- Модуль `equity_model.backtest`
- Файл результатов бэктеста (CSV/Parquet)
- Отчёт по тестам VaR

| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Паспорт методологии + дашборд |

**Цель:** Обеспечить прозрачность модели для внутреннего и внешнего аудита, а также визуализацию результатов для заказчика.

**Ключевые задачи:**
- Паспорт методологии: фиксация всех допущений
  - Нормальность доходностей внутри режима (опция: t-распределение)
  - Стационарность бет и корреляций внутри режима
  - Постоянство матрицы переходов (или MS-AR)
  - Обработка пропусков и ликвидности
- Дашборд:
  - Траектории симуляций для индекса IMOEX

- Регулярная отчётность:
  - Ежедневно: VaR (99%), ES, стресс-потери
  - Ежеквартально: отчёт о качестве модели (бэктестинг, тесты Купиека/Кристофферсена)

**Deliverables:**
- Модуль `equity_model.reporting`
