# Дорожная карта проекта Equity Model

> **Симуляция Монте-Карло с режимами "Бык/Медведь" для оценки стоимости акций (горизонт до 40 лет)**

---

## Обзор проекта

| Параметр | Значение |
| :--- | :--- |
| **Инструменты** | 260+ акций |
| **Горизонт прогноза** | 1 день — 40 лет |
| **Режимы рынка** | Bull / Bear (SMA-based) |
| **Методология** | Иерархическая модель Монте-Карло |
| **Статус** | В разработке (v0.1.0-dev) |

---

## 10 Этапов реализации

### **Этап 1** — Инфраструктура данных
| | |
| :--- | :--- |
| **Статус** | В работе |
| **Результат** | Витрина данных для 260+ инструментов |

**Цель:** Обеспечить чистый, непротиворечивый пайплайн данных для 260+ инструментов с учётом ликвидности и пропусков.

**Ключевые задачи:**
- Ежедневные цены закрытия (Total Return Index или с корректировкой на дивиденды)
- Фильтрация по ликвидности: исключение бумаг с >20% пропусков за 2 года
- Заполнение пропусков: forward fill для цен, удаление дней без торгов по рынку
- Минимальная история для калибровки: ≥2 лет непрерывных данных
- Разделение выборки: обучение (до T-365), тест (последние 365 дней), валидация (Walk-Forward 335 дней)

**Deliverables:**
- Модуль `equity_model.data` (loader, cleaner, validator)
- Витрина данных (Parquet): цены, логарифмические доходности, флаги пропусков, метаданные

### **Этап 3** — Калибровка иерархической модели с верификацией корреляций

| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Параметры β, ρ, σ для 4 режимов (BULL_LOW, BULL_HIGH, BEAR_LOW, BEAR_HIGH) |
| **Срок** | Q2 2026 |

**Цель:** Оценить параметры для всех уровней иерархической модели с учётом 4 рыночных режимов (Multi-Indicator + Volatility Overlay), используя исторические данные для верификации целевых корреляций и соответствия PFE Methodology.

**Ключевые задачи:**

1. **Идентификация режимов (4 режима):**
   - Multi-Indicator Detector (5 индикаторов: цена vs SMA-200, SMA-50 vs SMA-200, ширина рынка, объём, макро)
   - Volatility Overlay (VIX-RUS + историческая волатильность IMOEX)
   - Гистерезис (3 дня подряд для подтверждения смены режима)
   - Кризисный режим (Freeze на 63 дня при VIX > 40, просадка < -20%, корреляция > 0.90)

2. **Рыночные корреляции (Уровень 1):**
   - ρ_market по 4 режимам (BULL_LOW: ~0.50, BULL_HIGH: ~0.60, BEAR_LOW: ~0.70, BEAR_HIGH: ~0.85)
   - Correlation adjustment по режимам (от -0.10 до +0.25)
   - DCC-GARCH(1,1) для динамических условных корреляций
   - GARCH параметры по уровням волатильности (Low: α=0.08, β=0.90; High: α=0.15, β=0.80)

3. **Внутрикластерные корреляции (Уровень 2):**
   - Проверка ρ_cluster в разных режимах
   - Учёт групп истории (A, B, C, D) при расчёте корреляций
   - Ограничение liquid-illiquid корреляций (cap = 0.75)

4. **Калибровка акций (Уровень 3):**
   - β_bull_low, β_bull_high, β_bear_low, β_bear_high через регрессию на индекс
   - σ_idio по режимам
   - Консервативные множители по группам истории (Group A: 1.30/1.20, Group D: 1.00/1.00)
   - Liquidity Premium для неликвидных активов (множитель до 2.0)
   - Тест Чоу на структурные сдвиги бет во времени

5. **Валидация и соответствие PFE Methodology:**
   - Walk-Forward валидация (8-10 итераций, шаг 30 дней)
   - VaR Backtesting (тест Купиека, тест Кристофферсена)
   - Кризисная валидация на исторических периодах (2014, 2020, 2022)
   - PFE расчёт согласно PFE Methodology (Раздел 1.1, 1.2, 3.4.1, 3.4.2)
   - EAD = α × max EPE, α = 1.4

**Deliverables:**

| Артефакт | Описание | Формат |
| :--- | :--- | :--- |
| **Модуль `equity_model.calibration`** | Скрипты для калибровки режимов, DCC-GARCH, теста Чоу | Python Package |
| **Файл параметров модели** | β, ρ, σ по 4 режимам, кластерам, группам истории | CSV/Parquet |
| **Конфигурация режимов** | Параметры 9 режимов (4 активных), кризисные пороги | YAML (`regimes.yaml`, `risk.yaml`) |
| **Отчёт по верификации корреляций** | Сравнение модельных и фактических корреляций (MAE, RMSE) | PDF/Markdown |
| **Отчёт по валидации PFE** | Соответствие PFE Methodology (Раздел 1.1, 1.2, 3.4.1, 3.4.2) | PDF |
| **Отчёт по кризисной валидации** | Валидация на кризисах 2014, 2020, 2022 | PDF |
| **Unit-тесты** | 16+ тестов для калибровки и валидации | pytest |
| **Документация** | Методология калибровки, формулы, инструкции по обновлению | `docs/methodology/` |

**Критерии приемки:**

- Все инструменты из кластеров имеют калиброванные параметры (β × 4 режима, σ_idio)
- Параметры DCC-GARCH удовлетворяют условию стационарности (α + β < 1)
- MAE между модельными и фактическими корреляциями < 0.15
- Unit-тесты проходят успешно (16 тестов Этапа 2 + новые тесты Этапа 3)
- Отчёт содержит анализ как минимум 3 кризисных периодов (2014, 2020, 2022)
- Функция `get_model_parameters(date, regime)` возвращает полный набор параметров для 4 режимов
- Соответствие PFE Methodology (Раздел 1.1, 1.2, 3.4.1, 3.4.2)
- Кризисный режим (Freeze) протестирован и задокументирован
- Консервативные множители по группам истории (A, B, C, D) применены
- Liquidity Premium для неликвидных активов применён

**Зависимости:**

| Этап | Статус | Влияние |
| :--- | :--- | :--- |

**Риски:**

| Кризисный режим слишком часто активируется | Средняя | Настройка порогов (VIX > 40, drawdown < -20%) |

### **Этап 5** — Долгосрочная модель (до 40 лет)
| | |
| :--- | :--- |
| **Статус** | Запланировано |
| **Результат** | Марковская матрица переходов + инфляция |

**Цель:** Построить симуляции, где режимы сменяются по цепи Маркова с проверкой стационарности и возможностью добавления инфляции.

**Ключевые задачи:**
- Матрица переходов Маркова: P(Bull→Bull), P(Bull→Bear), P(Bear→Bull), P(Bear→Bear)
- Стационарное распределение π = (π_bull, π_bear) как собственный вектор
- Проверка: расхождение с исторической долей режимов <5%
- Модель Markov Switching (MS-AR) при нестационарности переходов
- Симуляция на 40 лет (40×365 дней) с иерархической структурой
- Инфляция: номинальные цены = реальные × (1 + инфляция)^t (база 4%)
- Критерий успеха: (1.04)^40 ≈ 4.8× рост за 40 лет

**Deliverables:**
- Модуль `equity_model.long_term`
- Файл матрицы переходов и стационарного распределения
- Отчёт по долгосрочным симуляциям

## Критерии успеха проекта

| Критерий | Целевое значение | Этап проверки |
| :--- | :---: | :---: |
| **Покрытие данных** | 260+ акций, <20% пропусков | Этап 1 |
| **Устойчивость кластеров** | ARI > 0.7 | Этап 2 |
| **Coverage Rate** | > 85% для 90% интервала | Этап 4 |
| **Тесты VaR** | p-value > 0.05 (Купиек, Кристофферсен) | Этап 8 |
| **Время пайплайна** | < 15 минут ежедневно | Этап 9 |
| **Документация** | Паспорт методологии + дашборд | Этап 10 |
